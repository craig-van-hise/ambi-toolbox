# Product Requirements Prompt (PRP) — 🔘 Pending

## 1. Project Context & Objectives
The AmbiToolbox has evolved into a sophisticated spatial audio suite, successfully transitioning to a unified Electron modular monolith. However, rapid development has introduced architectural debt: the root directory is heavily cluttered with reports and temporary files, and critical files such as `ToolViews.tsx` (1,278 lines), `main.ts` (613 lines), and `PlaybackContext.tsx` (615 lines) have expanded into "God Scripts" that violate single-responsibility principles. 

The objective of this PRP is to execute the Refactoring Recommendations Priority Roadmap in strict, deterministic phases. The end goal is a modularized frontend, a decoupled IPC backend, isolated context states, and a pristine repository root.

## 2. Technical Decisions & Dependencies
To eliminate cognitive load during execution, the following architectural decisions are mandated:
* **Directory Scaffolding:** You will create a new `docs/` directory at the project root, containing `docs/reports/` and `docs/PRPs/`.
* **Frontend Decomposition Pattern:** `ToolViews.tsx` will be strictly reduced to a routing/switcher component. Individual tools (e.g., AmbiLevel, AmbiTrim) must be isolated into `src/components/tools/[ToolName].tsx`. File queue logic must be abstracted into a generic `src/hooks/useFileQueue.ts` hook.
* **Backend Handler Pattern:** All `ipcMain.handle` and `ipcMain.on` declarations currently polluting `electron/main.ts` must be extracted into modular class methods within `electron/handlers/`. `main.ts` will only iterate over a registry of imported handler classes to attach them.
* **AmbiData Split:** The 491-line `AmbiData.ts` handler must be split into three distinct modules: `MetadataParser.ts` (JSON/OBU parsing), `PythonHeuristics.ts` (spawn wrapper for `ambi_data_heuristics.py`), and a shared `FfWrapper.ts`.
* **Audio State Decoupling:** `PlaybackContext.tsx` will be split. `AudioEngineContext` handles the WebAudio API / HTML5 Audio element and buffer management. `TransportContext` handles UI state (play, pause, current time, volume UI).
