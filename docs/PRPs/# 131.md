# Product Requirements Prompt (PRP) — 🔘 Pending

## 1. Project Context & Objectives
AmbiToolbox is migrating its core layout from a 2-column horizontal-split architecture to a 3-column vertical-split architecture. The current layout places the File Queue and Transport in the center, crowding tool-specific settings. The objective is to extract the File Management suite (Drop Zone, File Queue) into a dedicated Right Sidebar, and consolidate the execution/transport components at the bottom of the Center column. This will create a clean, consistent Top-Center stage for tool-specific parameter controls (e.g., AmbiRotate dials, Ambix2Opus bitrates).

## 2. Technical Decisions & Dependencies
* **Layout Engine:** Use strict Tailwind CSS Grid on the top-level container (likely `src/App.tsx` or `src/components/ToolViews.tsx`). Do not rely on floating elements or nested flex widths for the macro layout.
  * **Implementation:** `grid grid-cols-[250px_minmax(400px,_1fr)_320px] h-screen overflow-hidden`.
* **Component Relocation:** The unified `src/components/FileQueue.tsx` and `src/components/DropZone.tsx` (or `SmartDropZone.tsx`) must be physically moved within the DOM tree to a new `src/components/RightSidebar.tsx` component.
* **Vertical Flex Routing:** The Center column must act as a `flex flex-col h-full`. The Top-Center (Tool Settings) gets `flex-grow overflow-y-auto`. The Bottom-Center (Transport & Execute) gets `shrink-0 p-4 border-t border-gray-800`.
* **Deprecation:** Actively strip out any legacy drag-to-resize horizontal divider logic (`react-split-pane` or custom mouse-event hooks) previously used in the center view.
