# Product Requirements Prompt (PRP) — ✅ Completed

## 1. Project Context & Objectives
This phase targets the `AmbiTrim` tool, which is suffering from a layout migration regression and a fatal backend crash (`FFmpeg exited with code 8`). The crash occurs because the component relies on a deprecated local DropZone and is failing to pass a valid file path from the new global FileQueue to the `trim:generateProxy` IPC handler. The objective is to autonomously recover the legacy `AmbiTrim` component from Git (which contains the working WaveSurfer UI), strip its vestigial DropZone, and wire its data payload directly to the global FileQueue context.

## 2. Technical Decisions & Dependencies
* **Automated Git Archaeology:** The agent must search the repository history (1-3 weeks back) to find the iteration of `src/components/tools/AmbiTrim.tsx` that implements the WaveSurfer regions/waveform logic, bypassing the current corrupted state.
* **Context Wiring (The Crash Fix):** The agent must replace the local file-drop state with the global active file state (likely via `useFileQueue()` or `useAudioEngine()` hooks). The path of the globally selected file must be passed to `window.electronAPI.invoke('trim:generateProxy', activeFile.path)`.
* **Action Mapping:** To fit the 3-column layout, the local "Export Trimmed File" button must be deleted. Its logic must be mapped to the global execution button by setting `actionLabel: "Export Trimmed File"` in the global tool definition constants.
