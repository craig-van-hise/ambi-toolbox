# Product Requirements Prompt (PRP) — 🔘 Pending

## 1. Project Context & Objectives
The `AmbiTrim` tool is successfully rendering a visual WAV proxy, and the global audio streaming engine is functioning. However, the `wavesurfer.js` instance is completely isolated from the global `TransportContext`. The objective is to implement a two-way synchronization matrix so the visual playhead tracks global playback, and clicking the waveform scrubs the global audio stream.

## 2. Technical Decisions & Dependencies
* **Master Clock:** `TransportContext.tsx` is the single source of truth. `AmbiTrim.tsx` is a visual slave.
* **Audio Muting:** To prevent double-playback (the visual proxy vs. the global spatial downmix), the `wavesurfer` instance must be explicitly muted via `setVolume(0)`.
* **Seek Architecture:** Because the backend uses a chunked stream architecture, standard HTML5 audio seeking is invalid. We must intercept WaveSurfer's `interaction` event and route it to the global `commitSeek(time)` function.

### Phase 2: Visual Playhead Tracking (Global -> Local) — ✅ Completed
* **Objective:** Force the red playhead to move in sync with the global `currentTime`.
* **Instructions:**
    1. In `AmbiTrim.tsx`, add a new `useEffect` hook specifically for tracking time.
    2. Implement the following logic to safely push the global clock to the visualizer:
       ```typescript
       // Sync visual playhead with global transport
       useEffect(() => {
           if (wavesurfer.current) {
               try {
                   // wavesurfer expects time in seconds
                   const duration = wavesurfer.current.getDuration();
                   if (currentTime <= duration) {
                       wavesurfer.current.setTime(currentTime);
                   }
               } catch (e) {
                   // Ignore minor out-of-bounds errors during stream rebuilds
               }
           }
       }, [currentTime]);
       ```
