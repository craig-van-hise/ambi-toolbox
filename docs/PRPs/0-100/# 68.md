# Product Requirements Prompt: Fix "Ghost Lines" & Implement Triangle Flags

**Severity:** BLOCKER
**Diagnosis:**

1. **Double Lines:** Caused by the Region itself having a border *plus* the handle having a line.
2. **Square Handles:** `border-radius` and missing `clip-path` resulted in squares.
3. **Alignment:** Flags were not pointing "Inward".

**Goal:**

1. **Kill the Region Border:** The region must be a borderless color block.
2. **Draw 1 Line:** The Handle's pseudo-element acts as the *only* vertical line.
3. **Draw Triangles:** Use `clip-path` to cut the squares into flags.

## 1. The "Scorched Earth" CSS
status: ✅ Completed

**File:** `src/components/tools/AmbiTrim.tsx`
**Action:** Replace the `<style>` block entirely with this code.

```tsx
<style>{`
  /* 1. PLAYHEAD */
  #waveform-container ::part(cursor) {
    width: 2px !important;
    background-color: #ff0000 !important;
  }

  /* 2. REGION (KILL THE BORDERS) */
  /* This fixes the "Double Line" issue. We remove the border from the box itself. */
  #waveform-container ::part(region) {
    border: 0 !important; /* NO BORDER HERE */
    background-color: rgba(168, 85, 247, 0.2) !important;
    z-index: 10;
  }

  /* 3. HANDLE CONTAINER (Invisible Hit Zone) */
  #waveform-container ::part(region-handle) {
    width: 30px !important;            /* Large hit area */
    background-color: transparent !important; /* Invisible */
    cursor: ew-resize !important;
    outline: none !important;
  }

  /* 4. THE POLE (Single White Line) */
  /* Drawn down the exact center of the handle */
  #waveform-container ::part(region-handle)::before {
    content: "";
    position: absolute;
    left: 50%;
    top: 0;
    bottom: 0;
    width: 1px;       /* 1px razor sharp */
    background-color: white;
    transform: translateX(-50%);
    pointer-events: none;
    z-index: 15;
  }

  /* 5. THE FLAG BASE STYLING */
  #waveform-container ::part(region-handle)::after {
    content: "";
    position: absolute;
    top: 0;
    width: 12px;
    height: 12px;
    background-color: #a855f7; /* Purple */
    pointer-events: none;
    z-index: 20;
  }

  /* 6. LEFT HANDLE -> TRIANGLE POINTING RIGHT (▶) */
  /* [data-region-handle="start"] targets the Left handle */
  #waveform-container [data-region-handle="start"]::part(region-handle)::after,
  #waveform-container [data-region-handle="left"]::part(region-handle)::after {
    left: 50%; /* Attached to the pole */
    /* Triangle: Vertical Left edge, top flat, diagonal down-left */
    clip-path: polygon(0 0, 100% 0, 0 100%);
  }

  /* 7. RIGHT HANDLE -> TRIANGLE POINTING LEFT (◀) */
  /* [data-region-handle="end"] targets the Right handle */
  #waveform-container [data-region-handle="end"]::part(region-handle)::after,
  #waveform-container [data-region-handle="right"]::part(region-handle)::after {
    right: 50%; /* Attached to the pole */
    /* Triangle: Vertical Right edge, top flat, diagonal down-right */
    clip-path: polygon(0 0, 100% 0, 100% 100%);
  }

  /* 8. HOVER STATE */
  #waveform-container ::part(region-handle):hover::after {
    background-color: white !important; /* Flag turns white */
    transform: scale(1.1);
  }
  #waveform-container ::part(region-handle):hover::before {
    background-color: #a855f7; /* Pole turns purple */
    width: 2px;
  }
`}</style>

```
