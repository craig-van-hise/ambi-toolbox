# Product Requirements Prompt: Implement "AmbiTrim" Tool

**Context:**
We are adding a new tool called **AmbiTrim** to `AmbiToolbox`.
**Goal:** Create a lossless, format-agnostic audio trimmer that allows users to cut start/end points of massive multichannel Ambisonic files without re-encoding.
**Architecture:** Electron (Main) + React (Renderer) + FFmpeg (via `assets/bin/`).
**Core Challenge:** Electron cannot render large multichannel waveforms. We must implement a **Proxy Workflow**: Generate a lightweight stereo MP3/Ogg proxy for visualization -> Apply edit timestamps to the original master file.

---

## Phase 1: Dependency & Backend Logic (The Engine)
status: ✅ Completed

**Objective:** specific FFmpeg logic for proxy generation and lossless trimming.

1. **Install Dependencies:**
* Install `wavesurfer.js` and `wavesurfer.js` (specifically the Regions plugin) in the main `package.json`.


2. **Create Handler:** Create `electron/handlers/trim.ts`.
3. **Implement `generateProxy` function:**
* Input: `filePath` (string).
* Logic: Spawn FFmpeg from `assets/bin/`.
* Command: Downmix input to Stereo (`-ac 2`), Resample to 44.1kHz, encode to MP3 (`-f mp3`) at 128kbps.
* Output: Save to `app.getPath('temp')`. Return the temp path.


4. **Implement `executeTrim` function:**
* Input: `filePath`, `startTime` (seconds), `endTime` (seconds), `outputDir`.
* Logic: Use FFmpeg Stream Copy (`-c copy`).
* **Crucial:** Place `-ss` (seek start) *before* `-i` (input) for fast seeking.
* Command structure: `ffmpeg -ss <start> -to <end> -i <input> -c copy <output>`.

## Phase 4: Polish & Edge Cases
status: ✅ Completed

**Objective:** Ensure reliability and cleanup.

1. **Cleanup:** Ensure the temp proxy file is deleted from the user's disk when the component unmounts or a new file is dropped.
2. **Metadata Preservation:** Ensure the stream copy does not strip the B-Format `.amb` metadata (if FFmpeg usually strips it, flag this for the user).
3. **Error Handling:**
* If FFmpeg fails (e.g., corrupt input), show a Toast notification in the UI.
* If the user tries to trim a file < 1 second, disable the button.
