# Product Requirements Prompt (PRP) — 🔘 Pending

## 1. Project Context & Objectives
The `AmbiTrim` tool is successfully receiving time updates, but the playhead movement is quantized (~4Hz) because it relies on React state updates triggered by HTML5's `timeupdate` event. The objective is to achieve smooth 60fps visual rendering by allowing the muted `wavesurfer` proxy to "play" locally, utilizing the global transport state purely for start/stop triggers and drift correction.

## 2. Technical Decisions & Dependencies
* **Internal Rendering:** `wavesurfer.js` uses `requestAnimationFrame` for smooth UI updates during its own playback state.
* **Muted Mirroring:** The proxy must remain muted (`setVolume(0)`), but its internal transport state will mirror the global `isPlaying` state.
* **Drift Correction Threshold:** The global `currentTime` will be monitored. If the visual playhead drifts by more than `0.3` seconds from the master clock, a hard-sync (`setTime()`) will be issued.

## 3. Implementation Phases

### Phase 1: Play/Pause State Mirroring — ✅ Completed
* **Objective:** Tell the muted WaveSurfer instance to play and pause simultaneously with the global audio engine.

       // Mirror Transport Play/Pause for smooth 60fps internal rendering
       useEffect(() => {
           if (!wavesurfer.current) return;
           
           if (isPlaying) {
               // Only play if we are not at the absolute end of the file
               wavesurfer.current.play().catch(() => {});
           } else {
               wavesurfer.current.pause();
           }
       }, [isPlaying]);

### Phase 2: Refactor Tracking to Drift Correction — ✅ Completed
* **Objective:** Prevent the choppy 4Hz React state from overriding the smooth 60fps internal render, unless desync occurs.
* **Instructions:**
    1. Locate the existing `useEffect` that depends on `[currentTime, isDragging]`.
    2. Refactor it to calculate the difference between the local WaveSurfer time and the global `currentTime`.
    3. **Implementation:**
       ```typescript
       // Global Master Clock Sync & Drift Correction
       useEffect(() => {
           if (!wavesurfer.current || isDragging) return;
           
           const wsTime = wavesurfer.current.getCurrentTime();
           const timeDifference = Math.abs(wsTime - currentTime);
           
           // If the visualizer drifts more than 300ms from the master clock, snap it.
           // This prevents the 4Hz timeupdate event from making the playhead stutter.
           if (timeDifference > 0.3) {
               wavesurfer.current.setTime(currentTime);
           }
       }, [currentTime, isDragging]);
       ```
