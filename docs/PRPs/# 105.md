## 📋 PRP: Transport State Machine V3 (Native DOM Sync & Scrubbing Decoupling)

**Target Agent:** React/Electron Full-Stack Developer
**Subsystem:** Global Transport (`Transport.tsx`) & Orchestration Layer

### 1. Objective & Scope
status: ✅ Completed
Resolve a stream deadlocking issue where arbitrary-length looping freezes the transport, and fix a UX regression where timeline scrubbing causes backend process exhaustion. The agent must decouple visual timeline scrubbing from backend seek commands, and implement a `LOCKED_REBUILDING` state that relies strictly on native HTML5 Media events rather than brittle custom IPC handshakes.

### 2. Architecture Alignment
status: ✅ Completed
Refine the **Intent → Stream Commit** lifecycle using native DOM synchronization:
* **Scrubbing Isolation:** Dragging the transport handle must update *only* the local React visual state (`onChange`). It must absolutely **NOT** trigger an IPC seek. The backend IPC `seek` command must only fire on `onMouseUp`, `onTouchEnd`, or `onChangeCommitted`.
* **The Loop Lock:** When a loop boundary is hit (or a seek is committed), the frontend issues the `seek` IPC command and enters a `LOCKED_REBUILDING` state. The UI displays "BUFFERING" and ignores transport inputs.
* **Native Unlock Handshake:** DO NOT implement custom IPC events (like `stream-ready`) to detect stream health. Instead, use the React HTML5 `<audio>` element's native `onPlaying` or `onCanPlay` events to detect when the new pipeline's stream has arrived. When this native event fires, set `isRebuilding` to false and unlock the UI.
* **The Fail-Safe:** When entering `LOCKED_REBUILDING`, start a 3000ms `setTimeout`. If the native `onPlaying` event has not fired before the timeout completes, clear the lock, force the transport to a `PAUSED` state, and log an error. Clear the timeout if `onPlaying` fires successfully.

### 3. Technical Constraints
status: ✅ Completed
* **Non-Blocking:** All state locking, debouncing, and timeout timers must be handled purely in the React renderer process.
* **Backend:** The Electron main process should strictly handle tearing down and spawning the OBR/FFmpeg sidecars. Do not add custom stdout byte-sniffing.
* **State Integrity:** Ensure the loop boundary checking logic (`currentTime >= rightLocator`) is paused or bypassed while in the `LOCKED_REBUILDING` state to prevent rapid-fire loop triggers.
