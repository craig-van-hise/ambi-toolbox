# Product Requirements Prompt (PRP) — 🔘 Pending

## 1. Project Context & Objectives
This execution phase addresses critical UI/UX regressions introduced during the recent 3-column layout migration. The objective is to eliminate redundant execution buttons, establish dynamic nomenclature for global actions, enforce high-contrast structural boundaries, and apply rigid dimensional constraints to prevent the Transport UI from collapsing on narrow viewports.

## 2. Technical Decisions & Dependencies
* **Dynamic Button Nomenclature:** The global execute button in `src/components/ToolViews.tsx` currently concatenates `"Run " + activeTool.name`. This must be refactored. The `Tool` interface in `src/types.ts` or the tool configuration dictionary in `src/constants.ts` must be expanded to include an `actionLabel: string` property (e.g., `actionLabel: "Reduce"` for AmbiOrder, `actionLabel: "Convert"` for Ambix2Opus).
* **High-Contrast Dividers:** Replace existing subtle border utility classes (e.g., `border-gray-800`) with high-contrast `border-white` classes on the primary layout boundaries.
* **Responsive Constraints:** The center column's width collapse must be prevented at the CSS Grid level. The grid definition in the top-level wrapper must be updated from a flexible `1fr` to `minmax(450px, 1fr)` to guarantee the Transport component has adequate horizontal space.
