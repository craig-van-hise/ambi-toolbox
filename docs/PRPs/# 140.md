# Product Requirements Prompt (PRP) — ✅ Completed

## 1. Project Context & Objectives
This phase completes the migration of the `AmbiData` tool into the new 3-column architecture. In the legacy 2-pane center layout, `AmbiData` held its file management (DropZone/Queue) in the top half and its tool settings (Inspector/Data Cards) in the bottom half. The objective is to:
1. **Clear the Top Half:** Remove the vestigial DropZone and Queue from the top section of the center column.
2. **Migrate Up:** Move the "FILE IDENTITY" and Inspector cards from the bottom section into the top section.
3. **Finalize Transport:** Ensure the global Transport and "Apply Changes" button are the only elements in the Bottom-Center container.

## 2. Technical Decisions & Dependencies
* **DOM Relocation:** The agent must physically move the JSX for the data cards (Inspector, etc.) from their current container in `src/tools/AmbiData/index.tsx` to the primary return block that populates the Top-Center region.
* **Component Deletion:** Strip all local imports and JSX for `DropZone`, `FileQueue`, and `Transport` from the `AmbiData` file.
* **Action Mapping:** Ensure `actionLabel: "Apply Changes"` is set in the `AmbiData` tool definition so the global bottom button correctly triggers the data update logic.
