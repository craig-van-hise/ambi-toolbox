# Product Requirements Prompt (PRP)

## 1. Project Context & Objectives
status: ✅ Completed
**Project:** AmbiToolbox 
**Current State:** The audio transport looping mechanism fails on the second loop iteration. The UI halts and becomes unresponsive.
**Objective:** Implement a deterministic cache-busting mechanism (`seekNonce`) within the `PlayerState` to force the React state machine to rebuild the audio stream even when sequentially seeking to the identical timestamp.

## 2. Technical Decisions & Dependencies
status: ✅ Completed
* **Root Cause:** React's `useEffect` dependency array equality check prevents the Step 3 stream rebuild on the second loop iteration. `state.requestedSeekTime` is set to the same value (e.g., `0`) repeatedly.
* **Architecture Fix:** We will decouple the *intent* to seek from the *value* of the seek by introducing a `seekNonce` (number/timestamp) to the `PlayerState` interface. 
* **State Mutation:** `commitSeek` and `commitSeekInternal` will mutate `seekNonce` using `Date.now()`. The Step 3 Commit `useEffect` will observe `state.seekNonce` to guarantee execution on every loop jump.
