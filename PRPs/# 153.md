# Product Requirements Prompt (PRP) — 🔘 Pending

## 1. Project Context & Objectives
The `AmbiRotate` tool requires its local `yaw`, `pitch`, and `roll` UI state to be routed into the global spatial audio playback engine. This rotation must be strictly isolated: it should only affect the binaural stream when `AmbiRotate` is the currently active tool. Furthermore, adjusting the sliders should trigger a debounced real-time update to the audio stream.

## 2. Technical Decisions & Dependencies
* **Backend Invocation:** The C++ `obr_stream` sidecar accepts `--yaw`, `--pitch`, and `--roll` CLI arguments. 
* **State Interception:** `AudioEngineContext.tsx` will intercept the `commitStream` build process. If `settings.lastActiveTool === 'AmbiRotate'`, it will append the rotation settings to the HTTP query string.
* **Stream Rebuilding:** Because `obr_stream` is a statically spawned pipeline, "real-time" rotation requires rebuilding the stream. `AmbiRotate/index.tsx` will use a debounced `commitSeek(currentTime)` to smoothly rebuild the stream when sliders are released.

* **Objective:** Automatically rebuild the audio stream when a user stops dragging a rotation slider.
* **Instructions:**
    1. Open `src/tools/AmbiRotate/index.tsx`.
    2. Import the Transport hook: `import { useTransport } from '../../contexts/TransportContext';`
    3. Destructure the required state: `const { isPlaying, currentTime, commitSeek } = useTransport();`
    4. Add a debounced `useEffect` that listens to `yaw`, `pitch`, and `roll` to rebuild the stream transparently:
       ```typescript
       // Real-time Audio Preview Rebuild
       useEffect(() => {
           if (!isPlaying) return; // Only rebuild if audio is currently active
           
           const timer = setTimeout(() => {
               // Triggering a seek to the exact current time forces the AudioEngine 
               // to rebuild the HTTP stream with the newly updated Rotation settings.
               commitSeek(currentTime);
           }, 350); // 350ms debounce prevents pipeline spam while dragging

           return () => clearTimeout(timer);
       }, [yaw, pitch, roll]);
       ```
