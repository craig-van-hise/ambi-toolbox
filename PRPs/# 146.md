# Product Requirements Prompt (PRP) — 🔘 Pending

## 1. Project Context & Objectives
The `AmbiTrim` tool successfully renders a visual waveform proxy. However, the `wavesurfer.js` instance is isolated from the global audio playback. The objective is to achieve bi-directional synchronization between the global `TransportContext` and the local `AmbiTrim` visualizer. 

## 2. Technical Decisions & Dependencies
* **Clock Source:** The `TransportContext` is the absolute master clock. `wavesurfer` is strictly a visual slave.
* **Audio Muting:** To prevent double-playback (since the global `AudioEngine` handles the high-fidelity spatial downmix), the `wavesurfer` instance's volume must be forced to `0`.
* **Seek Interception:** Because the `AudioEngine` streams audio dynamically using `streamOffset`, `wavesurfer`'s default scrubbing behavior must be overridden to call `commitSeek(time)`.

## 3. Implementation Phases

### Phase 1: Context Integration & Muting — 🔵 Active
* **Objective:** Inject the global transport state and silence the local proxy.
* **Instructions:**
    1.  Open `src/components/tools/AmbiTrim.tsx`.
    2.  Import `useTransport` from `../../contexts/TransportContext`.

    5.  Add `mediaControls: false` to the config if it's not already there.

### Phase 2: Visual Playhead Tracking (Global -> Local) — 🔘 Pending
* **Objective:** Move the WaveSurfer playhead based on the global `currentTime`.
* **Instructions:**
    1.  In `AmbiTrim.tsx`, add a new `useEffect` that depends on `currentTime`.
    2.  Implement a local `isDragging` state (default `false`) to prevent jitter when the user is actively clicking/scrubbing.
    3.  **Logic Update:**
        ```typescript
        // Sync playhead with global transport
        useEffect(() => {
            if (wavesurfer.current && !isDragging) {
                // WaveSurfer expects time in seconds
                wavesurfer.current.setTime(currentTime);
            }
        }, [currentTime, isDragging]);
        ```
* **TDD Checkpoint:**
    * **AGENT INSTRUCTION:** "Set Phase status to 🔵 Active. Implement the tracking effect. Set status to ✅ Completed once the playhead visibly moves during playback."

### Phase 3: Scrubbing & Seek Overrides (Local -> Global) — 🔘 Pending
* **Objective:** Translate clicks on the waveform into global stream rebuilds.
* **Instructions:**
    1.  In the main `useEffect` where `wavesurfer` is initialized, add event listeners for user interaction.
    2.  Use the `interaction` event to trigger the global `commitSeek`.
    3.  Manage the `isDragging` state to pause Phase 2 tracking.
    4.  **Logic Update:**
        ```typescript
        ws.on('interaction', (newTime: number) => {
            // newTime is provided by wavesurfer in seconds
            commitSeek(newTime);
        });

        // Optional: manage isDragging for smoother UX if drag-to-seek is enabled
        ws.on('drag', () => setIsDragging(true));
        ws.on('interaction', () => setIsDragging(false)); 
        ```
