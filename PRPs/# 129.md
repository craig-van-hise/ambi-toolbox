
### Agent Instructions: Implement Ambix2BW64 Tool

**Objective:** Integrate the `ebu_adm_renderer` (`ear-utils`) into the AmbiToolbox suite to convert AmbiX files into BW64 containers with ADM metadata.

**Task 1: Legal & Compliance Integration**

* Append the EBU ADM Renderer's BSD-3-Clause-Clear license text and original copyright notice to `NOTICE.txt`.
* Update `EULA.md` to reflect the inclusion of this new third-party tool.

**Task 2: Binary Provisioning**

* Create a standalone macOS executable for the `ear-utils` Python package (using a tool like PyInstaller).
* Place the compiled binary (e.g., `ear-utils-mac-arm64`) directly into the `assets/bin/` directory.

**Task 3: Backend Handler Implementation**

* Create a new handler file at `electron/handlers/Ambix2BW64.ts` following the established modular handler pattern.
* Implement a function using Node's `child_process.spawn` to execute the bundled `ear-utils` binary with the `ambix_to_bwf` command.
* Expose this handler's functions by updating the bridge imports in `electron/shim.ts`.
* Register the necessary IPC routes for this tool within the application entry point at `electron/main.ts`.
* Expose the IPC invoke calls to the frontend by updating `electron/preload.ts`.

**Task 4: Frontend UI Construction**

* Create a new React component at `src/components/tools/Ambix2BW64.tsx`.
* Design the UI to include configuration toggles specific to the tool, such as Normalization (SN3D/N3D) and NFC distance.
* Mount this new component into the shared resizable partition system located in `src/components/ToolViews.tsx`.
* Wire the tool to accept file inputs from the global queue component at `src/components/FileQueue.tsx`.
