# Feature Specification: AmbiLevel
AmbiLevel allows users to adjust the gain or normalize Ambisonic audio files (1st, 2nd, 3rd, and 4th Order WAV/AMB) safely. 
**CRITICAL AUDIO REQUIREMENT:** Standard multi-channel normalizers process channels independently. Doing this to Ambisonics destroys the spatial image. AmbiLevel MUST use a fully linked approach. The exact same gain offset must be applied to ALL channels simultaneously to preserve the phase and amplitude relationships of the spherical soundfield.

## Backend Logic (Electron/FFmpeg - `electron/handlers/ambiLevel.ts`)
Implement the IPC handler to execute the FFmpeg commands. 

### Logic for "Manual Gain" Mode (Single Pass):
- Accept the user's dB offset.
- Use FFmpeg to apply a flat volume filter to the stream.
- **FFmpeg concept:** `ffmpeg -i input.wav -af "volume=XdB" -c:a pcm_s24le output.wav` (Ensure it outputs 24-bit PCM to prevent data loss).

### Logic for "Normalize to True Peak" Mode (Two-Pass):
- **Pass 1 (Analysis):** Run FFmpeg with the `volumedetect` filter (or `ebur128`) to scan the file and find the `max_volume` across the entire interleaved multi-channel file.
  - *Example:* `ffmpeg -i input.wav -af "volumedetect" -vn -sn -f null /dev/null`
  - Parse the output to find `max_volume: -X.X dB`.
- **Math Calculation:** Calculate the required offset. `Target dB - Max Volume dB = Gain Offset`. (e.g., if max volume is -3.0dB and target is -1.0dB, the offset is +2.0dB).
- **Pass 2 (Application):** Apply that specific gain offset uniformly to the entire file using the volume filter.
  - *Example:* `ffmpeg -i input.wav -af "volume=2.0dB" -c:a pcm_s24le output.wav`
