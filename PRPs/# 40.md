
**Role:** Lead Software Architect

**Status:**
**DIAGNOSTIC REQUIRED: AmbiOrder Black Screen.**
**Symptom:** Clicking the "AmbiOrder" tool causes the entire React app to crash (unmount), resulting in a black screen.
**Hypothesis:**

1. **API Bridge Failure:** `AmbiOrder` attempts to call `window.electron` on mount, but the bridge is missing/undefined in `preload.ts`.
2. **Component Incompatibility:** `AmbiOrder` passes legacy props (e.g., `onDrop`) to the newly refactored `SmartDropZone`, causing a prop mismatch or runtime undefined error.

**Task:**
Diagnose the crash via Console Logs and implement the fix.

**Step 1: Capture the Crash Log (The "Smoking Gun")**

1. Open the App.
2. Open Developer Tools (**Ctrl+Shift+I** / **Cmd+Opt+I**).
3. Click "AmbiOrder" to trigger the black screen.
4. **READ THE CONSOLE ERROR.**
* **If:** `Cannot read properties of undefined (reading 'runTask')` or `window.electron is undefined` → **Root Cause:** `preload.ts` is missing legacy exposure.
* **If:** `TypeError: props.onDrop is not a function` or similar inside `SmartDropZone` → **Root Cause:** `SmartDropZone.tsx` does not support legacy props.



**Step 2: Execute the Repair (Branching Logic)**

**PATH A: If the Error is API/Preload related**

* **Action:** You must verify `electron/preload.ts` explicitly exposes the legacy bridge.
* **Fix:** Ensure this exact block exists in `preload.ts`:
```typescript
contextBridge.exposeInMainWorld('electron', {
    runTask: (command, args) => ipcRenderer.invoke('run-task', command, args),
    selectFiles: () => ipcRenderer.invoke('dialog:openFile'),
    // ... any other legacy methods AmbiOrder uses
});

```



**PATH B: If the Error is SmartDropZone related**

* **Action:** Update `src/components/SmartDropZone.tsx` to support **Backward Compatibility**.
* **Fix:** Modify the Props interface and component to accept `onDrop` (legacy) alongside `onFilesLoaded` (new).
```typescript
// Required Interface Change
interface Props {
    onFilesLoaded?: (files: any[]) => void; // New AmbiRotate Prop
    onDrop?: (files: File[]) => void;       // Old AmbiOrder Prop
    children?: React.ReactNode;
    className?: string;
}
// Logic: If onDrop exists, bypass the new "expandPaths" logic and return raw Files.

```
