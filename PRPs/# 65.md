
# Product Requirements Prompt: Force Handle Visibility (CSS Override)

**Severity:** BLOCKER
**Context:** The Region is appearing with text ("TRIM ZONE"), proving the logic works. However, the drag handles are invisible.
**Goal:**

1. Remove the "TRIM ZONE" text.
2. Force the handles to be **White**, **Wide**, and **Visible** using specific attribute selectors.

## 1. Logic: Cleanup Region Config (`AmbiTrim.tsx`)

**Action:** Go to the `wsRegions.addRegion` call in your `useEffect`.

**Change:**

* Remove the `content` property completely.
* Keep `drag: true` and `resize: true`.

```typescript
// Inside ws.on('ready')...
wsRegions.addRegion({
  start: 5,           // arbitrary start
  end: duration - 5,  // arbitrary end
  color: 'rgba(168, 85, 247, 0.2)', // Purple Overlay
  drag: true,
  resize: true,
  // content: 'TRIM ZONE'  <-- DELETE THIS LINE
});

```

## 2. Style: The "Brute Force" CSS

**Action:** Replace your existing `<style>` block (or add this new one) inside the component's render return. We are targeting the `[part="region-handle"]` and `[data-region-handle]` attributes which are the "Shadow DOM" safe selectors for Wavesurfer.

**Copy this EXACT style block:**

```tsx
<style>{`
  /* 1. PLAYHEAD (Red Line) */
  #waveform-container ::part(cursor) {
    width: 2px !important;
    background-color: #ff0000 !important;
  }

  /* 2. REGION ITSELF (Purple Box) */
  #waveform-container ::part(region) {
    border: 1px solid rgba(168, 85, 247, 0.8) !important;
    z-index: 10;
  }

  /* 3. THE HANDLES (The Invisible Problem) */
  /* We target the 'part' attribute which works across Shadow DOM boundaries */
  #waveform-container ::part(region-handle) {
    width: 6px !important;            /* Make it thick */
    background-color: white !important; /* Make it bright */
    opacity: 1 !important;             /* Force visibility */
    cursor: ew-resize !important;
  }

  /* 4. THE "EARS" (Visual Grabbers) */
  /* Since we can't always rely on ::after in shadow parts, 
     we rely on the handle itself being a thick white bar. 
     If the handle is visible, the logic is solved. */
`}</style>

```
