# Product Requirements Prompt (PRP)

## 1. Project Context & Objectives
status: ✅ Completed
The user wants to support playback of `.aivu` files (Apple Immersive Video Universal). These are proprietary `.mov` containers that contain highly intensive stereoscopic MV-HEVC video and spatial audio (encoded in ASAF or APAC). 

The primary objective is to build a secure ingestion route that completely bypasses the massive video payload, leveraging FFmpeg's `audiotoolbox` integration to decode the spatial audio track into raw PCM for the streaming pipeline.

## 2. Technical Decisions & Dependencies
status: ✅ Completed
* **Video Stream Bypassing:** The pipeline MUST use the `-map 0:a:0` argument when decoding `.aivu` files. Without this, FFmpeg will attempt to process the 8K MV-HEVC video stream, causing memory exhaustion and pipeline failure.
* **Layout Protection:** Because the APAC/ASAF audio track contains up to 5th-order Ambisonics, we must apply the exact same `channelmap` filter protections used in the Opus fix. This prevents `swresample` from throwing layout-parsing exceptions when converting the audio to `f32le`.

status: ✅ Completed
