# Product Requirements Prompt (PRP) — ✅ Completed

## 1. Project Context & Objectives
The application requires a UI/UX polish pass. The static 3-column layout must be upgraded to a dynamic, resizable grid with click-and-drag divider lines and a collapsible right drawer. Additionally, the `AmbiRotate` tool and global Tool Titles must be scaled down visually by approximately 25% to increase workspace density.

## 2. Technical Decisions & Dependencies
* **Grid State:** Column widths (`leftWidth`, `rightWidth`) and drawer visibility (`isRightOpen`) will be managed via local state in `App.tsx`.
* **Drag Math:** `mouseMove` events on the `window` will recalculate widths based on `e.clientX`, constrained by `Math.max()` and `Math.min()` boundaries to prevent collapsing the layout into negative space.
* **Component Fluidity:** `Sidebar.tsx` must be stripped of its hardcoded `w-64` width so it inherits the width dictated by the parent grid.

## 3. Implementation Phases

### Phase 1: Resizable Grid & Drawer Toggle (`App.tsx` & `Sidebar.tsx`) — ✅ Completed
* **Objective:** Implement the dynamic grid, invisible drag zones, and right drawer toggle.
* **Instructions:**
    1. Open `src/components/Sidebar.tsx`. Remove the `w-64` class from the top-level `<aside>` element so it becomes `w-full`.
    2. Open `src/App.tsx`. Add state variables to `AppContent`:
       ```typescript
       const [leftWidth, setLeftWidth] = useState(190); // ~25% smaller than original 250px
       const [rightWidth, setRightWidth] = useState(300);
       const [isRightOpen, setIsRightOpen] = useState(true);
       const [isDragging, setIsDragging] = useState<'left' | 'right' | null>(null);
       ```
    3. Add the drag listener `useEffect`:
       ```typescript
       useEffect(() => {
           const handleMouseMove = (e: MouseEvent) => {
               if (isDragging === 'left') {
                   setLeftWidth(Math.max(150, Math.min(e.clientX, 400)));
               } else if (isDragging === 'right') {
                   setRightWidth(Math.max(200, Math.min(window.innerWidth - e.clientX, 600)));
               }
           };
           const handleMouseUp = () => setIsDragging(null);

           if (isDragging) {
               window.addEventListener('mousemove', handleMouseMove);
               window.addEventListener('mouseup', handleMouseUp);
           }
           return () => {
               window.removeEventListener('mousemove', handleMouseMove);
               window.removeEventListener('mouseup', handleMouseUp);
           };
       }, [isDragging]);
       ```
    4. Modify the root `div` in `AppContent` to remove `grid-cols-[...]` and use dynamic styles:
       ```tsx
       <div 
         className="grid h-screen w-screen bg-studio-bg text-studio-text overflow-hidden font-sans antialiased relative"
         style={{ gridTemplateColumns: `${leftWidth}px minmax(250px, 1fr) ${isRightOpen ? rightWidth + 'px' : '0px'}` }}
       >
       ```
    5. Add the invisible drag hitboxes between the components in the JSX, and a toggle button inside the `<main>` tag:
       ```tsx
       {/* Left Drag Handle */}
       <div 
           className="w-2 cursor-col-resize z-50 absolute h-full top-0 -ml-1 hover:bg-white/10 transition-colors"
           style={{ left: leftWidth }}
           onMouseDown={() => setIsDragging('left')}
       />
       
       {/* Main Content Area */}
       <main className="h-screen overflow-hidden flex flex-col relative border-l border-white">
           {/* Drawer Toggle Button */}
           <button 
               onClick={() => setIsRightOpen(!isRightOpen)}
               className="absolute top-4 right-4 z-50 p-1.5 bg-[#1E1E1E] border border-gray-700 rounded-md hover:bg-gray-700 text-gray-400 hover:text-white transition-colors shadow-lg"
               title="Toggle File Queue"
           >
               {isRightOpen ? "▶" : "◀"} {/* Replace with Lucide icons if preferred */}
           </button>
           // ... rest of main ...
       ```
    6. Ensure the Right Drag Handle is placed similarly, calculating its position from the right.
