# Product Requirements Prompt (PRP) — 🔘 Pending

## 1. Project Context & Objectives
This execution phase resolves critical layout clipping, component regressions, and Transport interaction bugs. The application window is allowing itself to be resized smaller than its internal CSS Grid can accommodate, resulting in the Right Sidebar clipping off-screen. Furthermore, the AmbiRotate tool's UI was improperly rewritten using generic HTML inputs, abandoning the custom `<Knob />` component library. Finally, the Transport's "Next" button state and volume slider flex behaviors are failing.

## 2. Technical Decisions & Dependencies
* **Global Minimum Dimensions:** The layout requires an absolute minimum width to support a 3-column architecture without crushing the UI. `250px (Left) + 480px (Center) + 320px (Right) = 1050px`. This must be enforced at the native OS level in `electron/main.ts` via the `BrowserWindow` configuration (`minWidth: 1050, minHeight: 700`).
* **AmbiRotate Component Integrity:** The AmbiRotate UI must revert to importing `src/tools/AmbiRotate/components/Knob.tsx`. The generic flex wrappers recently injected must be deleted.
* **Transport Flex Fix:** The Volume control overflow is caused by a rigid `width` or lacking `flex-shrink` within the `src/components/Transport.tsx` flex container. 
* **Next Button State:** The "forbidden" cursor indicates the `<button disabled={...}>` logic is evaluating to `true` improperly, or the SVG asset (e.g., `<MdSkipNext />`) has been stripped, leaving an empty, disabled hit-box.
