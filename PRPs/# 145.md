# Product Requirements Prompt (PRP) — ✅ Completed

## 1. Project Context & Objectives
The `AmbiTrim` tool is currently crashing the Electron backend with an `FFmpeg Exit Code 8`. This is caused by the backend handler (`trim.ts`) attempting to use the `libmp3lame` encoder, which is not compiled into the project's custom static FFmpeg binary. The objective is to replace the MP3 proxy generation workflow with a universally supported 16-bit PCM WAV workflow.

## 2. Technical Decisions & Dependencies
* **Audio Format Substitution:** The proxy generation will migrate from `.mp3` to `.wav`.
* **FFmpeg Encoder:** Replace `-c:a libmp3lame` with `-c:a pcm_s16le`.
* **FFmpeg Argument Removal:** Strip the `-b:a 192k` flag, as bitrates are not applicable to uncompressed PCM audio.
* **Frontend Blob Typing:** The frontend `Blob` constructor must be updated to use the `audio/wav` MIME type to ensure `wavesurfer.js` correctly decodes the IPC buffer.
