
### PRP #127: Stereo2Ambix DSP Engine Overhaul

**Objective:**
Rewrite the core processing loop of `py/stereo_to_ambix.py` to utilize a proper STFT for frequency-dependent PCA extraction, and replace the broken static-seed FFT diffusion with a continuous frequency-domain scattering matrix.

**Context & Constraints:**

* **Target File:** `py/stereo_to_ambix.py`.
* **Current Bugs:** Time-domain broadband PCA is causing violent gating. The `FDN16` class is unused. The `diffuse_ambient_fft` function resets its random seed every block, causing phase discontinuities.
* **Directives:** Do not attempt sample-by-sample FDN in Python (it will be too slow). Stick to the frequency domain, but implement it correctly using `scipy.signal.stft`.

**Execution Tasks:**

#### Task 1: Nuke the Time-Domain Loop

1. Delete `extract_primary_ambient`, `process_block`, and the manual `sf.SoundFile` block-reading loop inside `main()`.
2. Import the entire stereo file into memory as a NumPy array. (This is necessary for `scipy.signal.stft` to handle the overlapping windows correctly).

#### Task 2: Implement True STFT PCA (The "Flicker" Fix)

1. Pass the stereo array into `scipy.signal.stft` using a `hann` window, `nperseg=4096`, and `noverlap=2048`.
2. Iterate through the frequency bins ($k$) and time frames ($m$).
3. For each frequency bin, calculate the $2 \times 2$ covariance matrix $\mathbf{R}(k, m)$.
4. **Crucial:** Implement recursive temporal smoothing on the covariance matrix to prevent gating:
$\mathbf{R}_{smooth}(k, m) = 0.85 \cdot \mathbf{R}_{smooth}(k, m-1) + 0.15 \cdot \mathbf{R}(k, m)$
5. Extract the primary eigenvector from $\mathbf{R}_{smooth}$ and project the STFT bins to create the Direct ($P$) and Ambient ($A$) complex spectrograms.

#### Task 3: Continuous Frequency-Domain Diffusion (The FDN Fix)

1. Delete the unused `FDN16` class.
2. Rewrite `diffuse_ambient_fft` to accept the *entire* Ambient complex spectrogram ($A$) at once, rather than block-by-block.
3. Generate the random phase shift matrix $\mathbf{\Phi}$ exactly *once* for the entire spectrogram. Do not put `np.random.seed()` inside any loop.
4. Apply the $16 \times 16$ Hadamard mixing matrix to the phase-shifted bins.

#### Task 4: Reconstruct and Output

1. Route the Direct spectrogram ($P$) to the Spherical Harmonics matrix just as you did in `route_primary`.
2. Combine the Direct and diffused Ambient spectrograms.
3. Use `scipy.signal.istft` to perfectly reconstruct the time-domain AmbiX output with proper Overlap-Add (COLA) compliance.
