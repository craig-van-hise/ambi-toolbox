# Product Requirements Prompt (PRP) — ✅ Completed

## 1. Project Context & Objectives
This execution phase resolves UI redundancy and responsive layout regressions. The `AmbiRotate` module currently features a vestigial, duplicate transport bar that must be permanently removed. Furthermore, when the center column is compressed, both the `AmbiRotate` dials and the global `Transport` controls are "squishing" horizontally, breaking their bounding boxes. These flex containers must be updated to stack their children vertically. Finally, the agent previously hallucinated a new set of generic icons for the Transport bar; these must be reverted to the legacy iconography.

## 2. Technical Decisions & Dependencies
* **Component Deletion:** The timeline, play/pause controls, and "BINAURAL MONITOR" status text embedded within `src/tools/AmbiRotate/index.tsx` must be completely stripped from the JSX return block.
* **Responsive Stacking (`flex-wrap`):** To prevent horizontal squishing, the parent containers for the AmbiRotate dials and the Transport buttons must utilize Tailwind's `flex-wrap` utility. This allows elements to flow to a new line when the `minmax(250px, 1fr)` constraint of the center column forces a narrow viewport.
* **Surgical Icon Restoration:** The agent must *not* completely overwrite `src/components/Transport.tsx` with an old commit, as this would erase recent logical fixes (e.g., the Next button disabled state). Instead, it must inspect the Git history to extract *only* the legacy icon imports and JSX tags, manually porting them back into the current file.
