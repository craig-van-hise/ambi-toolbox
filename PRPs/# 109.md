# Product Requirements Prompt (PRP)

## 1. Project Context & Objectives
status: ✅ Completed
**Project:** AmbiToolbox
**Current State:** The backend streaming server uses an XY Cardioid matrix for the `render=stereo` preview path. This naturally rejects sound from the rear hemisphere, causing massive attenuation for objects panned behind the listener (e.g., 6 o'clock). 
**Objective:** Replace the backend XY Cardioid downmix with a Mid/Side (M/S) folddown matrix to achieve a mathematically flat 360° representation in stereo. We will verify this explicitly via a programmatic Python test script before touching the application code.

## 2. Technical Decisions & Dependencies
status: ✅ Completed
* **Root Cause:** The old FFmpeg `pan` filter included AmbiX Channel 3 (X - Front/Back axis). When a sound is behind the listener, the $X$ coefficient goes negative and phase-cancels the Omni ($W$) channel.
* **Architecture Fix:** We will use an M/S decoding matrix. This completely ignores the Front/Back axis (Channel 3 / $X$) and Up/Down axis (Channel 2 / $Z$), exclusively combining the Omni (Channel 0 / $W$) and Left/Right (Channel 1 / $Y$) components.
* **The Matrix Math:** * Left = 0.707 * W + 0.707 * Y
  * Right = 0.707 * W - 0.707 * Y
  * **New FFmpeg Syntax:** `pan=stereo|c0=0.707*c0+0.707*c1|c1=0.707*c0-0.707*c1`
* **Dependencies:** The test script utilizes `numpy` and `soundfile`, which are already verified as available in the project's Python environment.

    ```python
    import numpy as np
    import soundfile as sf
    import subprocess
    import os

    FS = 48000
    DURATION = 4.0  
    FREQ = 440.0    
    IN_FILE = "synthetic_ambix_sweep.wav"
    OUT_CARDIOID = "out_cardioid.wav"
    OUT_MS = "out_ms.wav"

    def generate_ambix_sweep():
        t = np.linspace(0, DURATION, int(FS * DURATION), endpoint=False)
        tone = np.sin(2 * np.pi * FREQ * t)
        theta = np.linspace(0, 2 * np.pi, len(t), endpoint=False)
        
        W = tone * 1.0
        Y = tone * np.sin(theta)  
        Z = tone * 0.0            
        X = tone * np.cos(theta)  
        
        ambix_data = np.vstack((W, Y, Z, X)).T
        sf.write(IN_FILE, ambix_data, FS, subtype='PCM_24')

    def run_ffmpeg_matrix(matrix_string, out_file):
        cmd = ["ffmpeg", "-y", "-i", IN_FILE, "-af", matrix_string, out_file]
        subprocess.run(cmd, stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)

    def calculate_rms_at_time(audio_data, time_sec, window_ms=50):
        center_sample = int(time_sec * FS)
        half_window = int((window_ms / 1000.0 * FS) / 2)
        start = max(0, center_sample - half_window)
        end = min(len(audio_data), center_sample + half_window)
        
        segment = audio_data[start:end]
        total_energy = np.sum(segment, axis=1)
        rms = np.sqrt(np.mean(total_energy**2))
        return 20 * np.log10(rms) if rms > 0 else -999.0

    def analyze_output(filename, label):
        data, _ = sf.read(filename)
        front_db = calculate_rms_at_time(data, 0.0)
        rear_db = calculate_rms_at_time(data, 2.0)
        print(f"--- {label} ---")
        print(f"Front (0°)   : {front_db:.2f} dBFS")
        print(f"Rear  (180°) : {rear_db:.2f} dBFS")
        print(f"Rear Attenuation: {front_db - rear_db:.2f} dB\n")

    if __name__ == "__main__":
        generate_ambix_sweep()
        cardioid_pan = "pan=stereo|c0=0.5*c0+0.354*c3+0.354*c1|c1=0.5*c0+0.354*c3-0.354*c1"
        run_ffmpeg_matrix(cardioid_pan, OUT_CARDIOID)
        ms_pan = "pan=stereo|c0=0.707*c0+0.707*c1|c1=0.707*c0-0.707*c1"
        run_ffmpeg_matrix(ms_pan, OUT_MS)
        
        analyze_output(OUT_CARDIOID, "OLD MATRIX: XY Cardioid")
        analyze_output(OUT_MS, "NEW MATRIX: Mid/Side (Flattened)")
        
        os.remove(IN_FILE)
        os.remove(OUT_CARDIOID)
        os.remove(OUT_MS)
    ```
