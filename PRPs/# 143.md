# Product Requirements Prompt (PRP) — ✅ Completed

## 1. Project Context & Objectives
This phase addresses critical regressions in the `AmbiTrim` tool. The UI is conditionally rendering a vestigial DropZone instead of remaining persistently visible, the component includes a redundant local transport (purple play button), and the backend is crashing with `FFmpeg exited with code 8`. The objective is to make the Waveform UI unconditionally visible, delete the local transport, constrain the container size, and fix the malformed IPC payload causing the backend crash.

## 2. Technical Decisions & Dependencies
* **Unconditional Rendering:** The `AmbiTrim` component must return the Waveform UI (container, zoom slider, time inputs) directly. It must *not* use conditional logic to show a DropZone when no file is selected.
* **IPC Payload Fix (Code 8):** The `useEffect` that triggers `trim:generateProxy` must strictly extract and pass `activeFile.path` (a string). If the entire `activeFile` object is passed, `electron/handlers/trim.ts` will feed `[object Object]` to FFmpeg, resulting in exit code 8.
* **UI Constraints:** The large purple local play button must be deleted. The waveform's parent container must receive a constrained height (e.g., `h-[200px]` or `max-h-64`) to prevent it from consuming too much vertical space.

### Phase 2: Resolving the IPC Crash (Code 8) — ✅ Completed
* **Objective:** Fix the malformed argument causing the FFmpeg proxy generator to crash.
* **Instructions:**
  1. In `src/components/tools/AmbiTrim.tsx`, locate the `useEffect` that listens for the active file and calls the backend.
  2. Ensure the IPC invocation is strictly passing the path string: 
     `window.electronAPI.invoke('trim:generateProxy', activeFile.path)`. Do NOT pass the bare `activeFile` object.
  3. Open `electron/handlers/trim.ts`. Locate the `trim:generateProxy` IPC handler.
  4. Add a console log at the very top of the handler: `console.log('Received path for proxy:', inputPath)`. 
  5. Verify the FFmpeg argument array. It should look similar to: `['-y', '-i', inputPath, '-af', 'pan=stereo|c0=c0|c1=c0', tempOutputPath]`. Ensure `inputPath` is valid.
* **TDD Checkpoint:**
