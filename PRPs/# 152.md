# Product Requirements Prompt (PRP) — ✅ Completed

## 1. Project Context & Objectives
Two bugs must be eradicated:
1. The global Transport "Play" button fails to cold-boot the `activeFile` if the user has not double-clicked a track first.
2. `AmbiTrim` throws an unhandled `TypeError: Failed to fetch` when rapidly switching files, caused by `wavesurfer.destroy()` interrupting an active asynchronous `.load()` call.

## 2. Technical Decisions & Dependencies
* **Strict Transport Handoff:** The Play button in `Transport.tsx` must utilize a dedicated handler function that checks the engine state *before* falling back to standard play/pause toggling.
* **Promise Rejection Swallowing:** `wavesurfer.load()` must be chained with a `.catch()` block to gracefully handle aborts during component unmounting.
* **Garbage Collection:** `URL.revokeObjectURL()` must be implemented to prevent Blob memory leaks when `proxyPath` changes.

## 3. Implementation Phases

### Phase 1: Enforce Smart Play Handoff (`Transport.tsx`) — ✅ Completed
* **Objective:** Fix the "Dead Play Button" by ensuring it cold-boots the selected file.
* **Instructions:**
    1. Open `src/components/Transport.tsx`.
    2. Ensure `useFileQueue` and `useTransport` are imported.
    3. Destructure the required state:
       `const { activeFile } = useFileQueue();`
       `const { currentFile, togglePlayPause, setCurrentFile } = useTransport();`
    4. Create (or overwrite) the master play button handler:
       ```typescript
       const handleMasterPlay = () => {
           // If the transport is empty, but we have a selected file in the UI...
           if (!currentFile && activeFile) {
               // Safely extract the path (handling both object and string shapes)
               const targetPath = typeof activeFile === 'string' ? activeFile : activeFile.path;
               if (targetPath) {
                   setCurrentFile(targetPath, true); // Cold-boot and play
                   return;
               }
           }
           // Otherwise, behave normally (pause if playing, play if paused)
           togglePlayPause();
       };
       ```
    5. Locate your primary Play/Pause `<button>` element and bind it: `onClick={handleMasterPlay}`.
