# Product Requirements Prompt (PRP)

## 1. Project Context & Objectives

The AmbiToolbox currently streams standard `.wav` and `.amb` files successfully through a 3-stage `Decoder -> OBR -> Encoder` pipeline (for binaural) and a legacy FFmpeg stereo downmix pipeline. We are expanding the ingest capability to support a massive array of standard media containers (`.aac`, `.caf`, `.flac`, `.m4a`, `.mkv`, `.mov`, `.mp3`, `.mp4`, `.ogg`, `.opus`, `.webm`) and proprietary spatial formats (`.iamf`, `.mat`, `.aivu`).

The goal is a seamless "Drop & Play" experience where the backend automatically extracts the audio stream from video containers and routes proprietary formats through specialized pre-decoders before feeding them into the real-time Opus streaming endpoints.

## 2. Technical Decisions & Dependencies

* **Audio Stream Extraction:** To handle video containers (`.mkv`, `.mp4`, `.webm`, `.mov`), FFmpeg must explicitly map the first audio stream using the `-map 0:a:0` flag.
* **Ingestion Routing Pattern:** Native FFmpeg cannot decode `.iamf`, `.mat`, or `.aivu`. The agent will create an `IngestionRouter` module. If a proprietary format is detected, the router will trigger a synchronous/cached Python transcode to a temporary `.wav` file (`.ambi_tmp.wav`) in the system temp directory. The streaming endpoints will then stream this proxy `.wav` file instead of the unsupported original.
* **UI Updates:** All `DropZone` and `SmartDropZone` components must be updated to accept the new comma-separated extension list.

* **Objective:** Modify the existing streaming decoders to isolate audio streams, preventing video-stream corruption in the pipeline.
* **Instructions:**

2. Locate `decoderArgs` inside `createObrPipeline`.

4. Open `electron/main.ts`.
5. Locate the legacy `isLegacyStream` FFmpeg argument array (`args`).
6. Inject `-map`, `0:a:0` immediately after the input file (`-i`, `filePath`).

### Phase 2: The Ingestion Routing Layer (Proprietary Formats)

* **Objective:** Intercept `.iamf`, `.mat`, and `.aivu` files and proxy them via temporary WAV conversion before streaming.
* **Instructions:**
1. Create `electron/handlers/IngestionRouter.ts`.
2. Implement `async function prepareStreamTarget(originalPath: string): Promise<string>`.
3. If `originalPath` ends with `.iamf`, `.mat`, or `.aivu`:
* Generate a unique hash for the file path to serve as a cache key.
* Define a temp path: `os.tmpdir() + hash + '.ambi_tmp.wav'`.
* If the temp file exists, return it immediately (cache hit).
* If not, use `child_process.spawn` to trigger a Python sidecar (`py/format_decoder.py`) that converts the proprietary file to the temp WAV file. (Assume the Python script handles the math/parsing; just wire the execute command).
* Return the new `.tmp.wav` path.


4. If the format is standard, return the `originalPath` unchanged.
5. Update `main.ts` `/stream` and `/obr-stream` routes to await `prepareStreamTarget(filePath)` before probing or spawning pipelines. Use the returned path as the new `filePath`.
