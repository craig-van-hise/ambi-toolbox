
### PRP 42-4: UI Layout Correction & Vertical Response Fix

**Objective:** Fix the "Action Bar" regression (restore stacked layout) while enforcing vertical responsiveness on the Drop Zone.

> **Instruction for Agent:**
> We have a UI regression. The "Convert" button has incorrectly moved to the right of the settings. We need to restore the original "Stacked" look while keeping the vertical shrinking logic.
> **You must apply this specific Flexbox structure to the Main Container of ALL 7 TOOLS:**
> **1. The Parent Container (Wrapper)**
> * **Class:** `h-screen flex flex-col overflow-hidden`
> * **Purpose:** Locks the tool to the window height.
> 
> 
> **2. The Drop Zone Section (Middle)**
> * **Class:** `flex-1 min-h-0 overflow-y-auto`
> * **CRITICAL LOGIC:** The `min-h-0` class is the key. It tells the browser "this section is allowed to shrink smaller than its content." Without this, the drop zone refuses to shrink when the window gets small.
> 
> 
> **3. The Action Bar (Bottom/Footer)**
> * **Class:** `flex-none border-t bg-gray-50 p-4 flex flex-col gap-4`
> * **CONSTRAINT:** You MUST use `flex-col` here.
> * **Wrong:** Button floats to the right of the options.
> * **Right:** Options sit on top. Button sits below, spanning full width.
> 
> 
> * **Button Style:** Ensure the main action button has `w-full` (width: 100%).
> 
> 
> **Execution Steps:**
> 1. Open `Ambix2IAMF/index.tsx` (and all other tool files).
> 2. Locate the bottom `<div>` (Action Bar).
> 3. Force it to be a vertical stack (`flex-col`).
> 4. Verify the Drop Zone container above it has `min-h-0`.
> 5. Do **NOT** change the visual styling (colors, borders) of the inputs; only fix the positioning.
>
