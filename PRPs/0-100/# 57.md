## 1. Harden the Backend (`generateProxy`)

**File:** `electron/handlers/trim.ts`
**Objective:** Rewrite the FFmpeg command to be aggressively compatible.
**Constraint:** Do not assume the input sample rate. Force resampling.

**Refactor `generateProxy` logic:**

```typescript
// OLD/CURRENT (Likely causes issues):
// ffmpeg -i input -ac 2 output.mp3

// NEW (Strict Web Compatibility):
// 1. -ac 2: Downmix to Stereo (Crucial for Ambisonics).
// 2. -ar 44100: Resample to standard Web rate.
// 3. -b:a 192k: High quality enough for QC.
// 4. -map_metadata -1: Strip weird metadata that might confuse the browser.
// 5. -y: Overwrite existing.

const args = [
  '-y',
  '-i', filePath,
  '-ac', '2',              // Force Stereo
  '-ar', '44100',          // Force standard Sample Rate
  '-c:a', 'libmp3lame',    // Explicitly use MP3 encoder
  '-b:a', '192k',
  '-map_metadata', '-1',   // Clean metadata
  outputPath
];

```
