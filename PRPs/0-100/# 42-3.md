### PRP 42-3: Universal Responsive Layout Refactor

**Objective:** Standardize the viewport structure across all 7 tools to prevent UI overflows and ensure consistent control placement.

> **Instruction for Agent:**
> Refactor the main container layout for **ALL 7 TOOLS** (Ambix2Opus, Ambix2Bin, Ambix2IAMF, Ambix2CAF, AmbiOrder, AmbiSwap, and AmbiRotate).

>

> * Class: `flex-none border-t bg-gray-50 p-4` (or matching current theme).
> * Logic: This area contains the "Convert/Render" buttons and configuration toggles. It must remain pinned to the bottom.
> 
> 
> 
>
