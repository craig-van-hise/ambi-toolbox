# Product Requirements Prompt: AmbiTrim Diagnostic Instrumentation

**Objective:** Implement comprehensive logging and data validation across the entire "AmbiTrim" pipeline to identify why the waveform is flat/silent.
**Philosophy:** "Trust Nothing, Log Everything." We need to verify the file size, byte content, and object types at every handover.

## Phase 1: Backend Instrumentation (`trim.ts`)
status: ✅ Completed

**Goal:** Prove that FFmpeg is actually generating valid audio data and that Node is reading it correctly.

**Action:** Modify `generateProxy` to log specific metrics *before* returning data.

```typescript
// In electron/handlers/trim.ts

// ... after fs.readFileSync(outputPath) ...

const fileBuffer = fs.readFileSync(outputPath);

// DIAGNOSTIC LOG 1: Backend Reality Check
console.log("--- [DEBUG] BACKEND DIAGNOSTICS ---");
console.log("1. Output File Path:", outputPath);
console.log("2. File Exists:", fs.existsSync(outputPath));
console.log("3. File Size (Bytes):", fileBuffer.byteLength);
console.log("4. First 10 Bytes:", fileBuffer.subarray(0, 10)); // Should see MP3 header bytes (e.g. FF FB)
console.log("-----------------------------------");

// If size is < 1000 bytes, we know FFmpeg failed silently.
if (fileBuffer.byteLength < 1000) {
    throw new Error(`[DEBUG] Generated proxy is suspiciously small: ${fileBuffer.byteLength} bytes.`);
}

return fileBuffer; 

```

## Phase 2: Bridge/Preload Instrumentation (`preload.ts`)
status: ✅ Completed

**Goal:** Verify that the data survives the IPC serialization without getting mangled.

**Action:** Wrap the `generateProxy` call in the preload script with logging.

```typescript
// In electron/preload.ts

generateProxy: async (filePath: string) => {
    console.log("[DEBUG] Bridge invoking generateProxy for:", filePath);
    const result = await ipcRenderer.invoke('trim:generateProxy', filePath);
    
    console.log("--- [DEBUG] BRIDGE DIAGNOSTICS ---");
    console.log("1. Received Type:", typeof result);
    console.log("2. Is Buffer?", Buffer.isBuffer(result));
    console.log("3. Is Uint8Array?", result instanceof Uint8Array);
    console.log("4. Data Length:", result.length || result.byteLength || result.data?.length);
    console.log("----------------------------------");
    
    return result;
}

```
