### PRP 42-5: Fix Queue Overlap (Enforce Vertical Flow)

**Objective:** Stop the File Queue from floating/overlapping the Drop Zone. Force it to render as a static list *below* the Drop Zone.

> **Instruction for Agent:**
> The "File Queue" list is currently floating (using `absolute` or `fixed` positioning) and obscuring the Drop Zone when the window resizes. We must change it to be a standard block element that sits *below* the Drop Zone.
> **1. Update the Main Container Logic (All Tools):**
> * Go to the "Middle Section" (the `flex-1 min-h-0` container we defined in PRP 4).
> * Inside this container, wrap the contents in a vertical flex stack:
> ```tsx
> // The Scrollable Middle Container
> <div className="flex-1 min-h-0 overflow-y-auto p-4">
>     <div className="flex flex-col gap-4 h-full">
>         {/* 1. The Drop Zone */}
>         <SmartDropZone ... />
> 
> ```
> 
> 
> 
> 

> ```
>         {/* 2. The Queue (Conditional Rendering) */}
>         {files.length > 0 && (
>             <div className="flex-none"> {/* Container for the queue */}
>                 <QueueList files={files} ... />
>             </div>
>         )}
>     </div>
> </div>
> ```
> 
> ```
> 
> 
> **2. Remove "Floating" Styles from the Queue Component:**
> * Inspect the `QueueList` (or `FileList`) component implementation.
> * **Delete** any CSS classes that detach it from the flow, specifically:
> * `absolute`
> * `bottom-0` / `top-0`
> * `inset-x-0`
> * `z-50` (or high z-index)
> 
> 
> * **Apply** standard block styling:
> * Give it a background (e.g., `bg-gray-800`), rounded corners (`rounded-lg`), and padding (`p-2`) so it looks like a distinct section below the drop zone.
> 
> 
> 
> 
> **3. Verify the Drop Zone Height:**
> * Ensure the `SmartDropZone` itself does **not** have `h-full`.
> * It should have a specific height (e.g., `h-64` or `min-h-[200px]`) or `flex-1` if you want it to fill empty space *until* files are added.
> * *Recommended:* Set `SmartDropZone` to `flex-none h-64` (fixed height) OR `flex-1` (grow), but ensure the parent `flex-col` handles the stacking so the Queue is pushed down, not covered.
