
# Product Requirements Prompt: Fix Flat Waveform (Switch to WebAudio)

**Diagnosis:**
The audio plays because the `MediaElement` backend is successfully streaming the Blob to an audio tag.
The waveform is flat because `MediaElement` cannot extract peak data from a Blob for visualization.
**Solution:**
Switch Wavesurfer to the `WebAudio` backend. This forces the browser to decode the Blob into PCM data, which Wavesurfer uses to draw the waveform.

## 1. Frontend: Backend Switch (`AmbiTrim.tsx`)

**File:** `src/components/tools/AmbiTrim.tsx`
**Task:** Update the `WaveSurfer.create` configuration.

**Change:**

1. Set `backend: 'WebAudio'` (or remove the `backend` line entirely, as WebAudio is usually the default).
2. Keep `normalize: true` (just in case).
3. Keep the `blob:` URL loading logic.

```typescript
// Inside useEffect or init function:

const wavesurfer = WaveSurfer.create({
  container: containerRef.current,
  waveColor: '#a855f7',
  progressColor: '#3b82f6',
  cursorColor: '#ffffff',
  height: 128,
  
  // CRITICAL FIX:
  // Force WebAudio. This decodes the Blob to get visualization data.
  backend: 'WebAudio', 
  
  // Visuals
  normalize: true,
  barWidth: 2,
  barGap: 1,
  barRadius: 2,
});

// Load the Blob URL
wavesurfer.load(blobUrl);

```
