# Product Requirements Prompt (PRP): Binaural Pipeline Fix & TDD Implementation

## 1. Context & The Bug
status: ✅ Completed

Your previous implementation of the `sofalizer` filter graph crashed the FFmpeg process.

* **The Error:** `[Parsed_sofalizer_1] Failed to parse '180' as channel number.`
* **The Cause:** You passed raw azimuth/elevation numbers into the `sofalizer` `speakers` argument. FFmpeg rejected them as invalid channel names.
* **The Fix:** When using a custom `pan` layout with 26 channels, the `pan` filter outputs them as `c0, c1, c2 ... c25`. Your `sofalizer` argument must map these exact channel names to their coordinates.
* **Correct Syntax Example:** `sofalizer=sofa='...':speakers='c0 0 0|c1 180 0|c2 90 0|...|c25 -45 0'`

## 2. Mandatory TDD Requirement (Automated Testing)
status: ✅ Completed

You are no longer allowed to guess if the FFmpeg process works. The user will not act as your terminal output reader. You must write an automated test script to verify your fix.

**Action 1: Create the Test Script**
Create a new file: `scripts/test-binaural.js`.
This Node script must:

1. Use `child_process.spawn` to run your FFmpeg binary exactly as the backend would.
