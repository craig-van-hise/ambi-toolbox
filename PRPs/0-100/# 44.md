### PRP 44: The Collapsible "Input vs. Edit" Layout

**Objective:** Solve the vertical overflow by allowing the Drop Zone and Queue to collapse into a "Mini Bar" when the Rotator is active.

> **Instruction for Agent:**
> The `AmbiRotate` UI is too tall. We need to implement a **Collapsible Input Section** so the Drop Zone/Queue can be hidden when the user is working in the Rotator.
> **1. State Management:**
> * In `AmbiRotate/index.tsx`, add a state: `const [isInputExpanded, setInputExpanded] = useState(true);`
> * **Logic:** When a user selects a file from the Queue (setting the `activeFile`), automatically set `setInputExpanded(false)`.
> 
> 
> **2. Create the "Collapsible Wrapper":**
> * Wrap the **Drop Zone** and **Queue** inside a new container div.
> * **Header (Always Visible):** Create a thin header bar (approx `h-10`) above this wrapper.
> * **Text:** "📂 Input Files ({files.length})"
> * **Action:** Clicking this bar toggles `setInputExpanded(!isInputExpanded)`.
> * **Style:** `flex items-center justify-between bg-gray-800 p-2 text-xs font-bold text-gray-400 cursor-pointer hover:bg-gray-700 rounded-t-lg`.
> 
> 
> * **Body (Conditionally Visible):**
> * If `isInputExpanded` is **TRUE**: Render the Drop Zone and Queue normally.
> * If `isInputExpanded` is **FALSE**: Hide them (render `null` or `hidden`).
> 
> 
> 
> 
> **3. Optimize the Rotator Card (Vertical Space Savings):**
> * **Move the "Render" Button:** The big red "Render Rotated File(s)" button is currently inside the Rotator Card. **Move it out.**
> * Place it in the **Global Action Bar** (the fixed footer at the very bottom of the screen) where the "Convert" button lives in other tools.
> * This saves ~60px of height inside the scrolling area.
> 
> 
> **4. Scrollable Container:**
> * Ensure the `RotatorInterface` container has `overflow-y-auto` so if the screen is *extremely* short, the user can still scroll the sliders.
> 
> 
> **User Experience Goal:**
> 1. User drags files (Input Expanded).
> 2. User clicks a file.
> 3. Input Section snaps shut (Collapsed).
> 4. Rotator appears and fills the screen.
> 5. User needs to add more files? They click the "Input Files" header to open it back up.
>
