**2. Audio Engine Architecture (Hybrid Strategy)**
You must implement a hybrid approach to handle **Arbitrary Order Ambisonics** (e.g., 7th Order) without crashing the browser.

* **Part A: The Preview Engine (Frontend)**
* **Library:** Use `JSAmbisonics` (vendor the `.js` file if necessary) for real-time binaural monitoring.
* **The "Proxy" Pattern:**
* Detect the Input Order.
* **If Order  3:** Load normally.
* **If Order  3 (e.g., 7th Order):** **Slice** the buffer to the first 16 channels (3rd Order) *before* feeding it to the JS decoder.
* *Goal:* The user monitors a "Low Res Proxy" to make decision, but the Export uses the full file.




* **Part B: The Export Engine (Backend)**
* **Language:** Python (via `resources/scripts/rotate_ambisonics.py`).
* **Library:** `numpy` and `scipy`.
* **Math Requirement:** Implement **Recursive Wigner-D Matrices** for rotation.
* **CRITICAL:** Do NOT hardcode support for only orders 1-3. The script must accept *any* order (N) and generate the correct rotation matrix dynamically.


* **Electron Handler:** Create `electron/handlers/ambirotate.ts` to spawn this Python script with arguments: `input_path`, `output_path`, `yaw`, `pitch`, `roll`.
