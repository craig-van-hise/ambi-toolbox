### 💡 Why we are doing this

The "Script Tag" method relies on the file being in the perfect folder (`public/` vs `static/` vs `assets/`). Electron builders often move these folders around. By using `npm install` and `import`, Webpack/Vite will bake the library code *inside* your `bundle.js`, so it is physically impossible for it to be missing.
