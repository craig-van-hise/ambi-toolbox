**1. Audio Engine Strategy (The "Proxy" Pattern)**

* **A. Real-Time Preview (Frontend - `src/tools/AmbiRotate/PreviewEngine.ts`)**
* **Logic:**
1. Detect Input Order.
2. **If Order  3:** Load directly into `JSAmbisonics` (or `ambisonics` lib).
3. **If Order  3 (e.g., 7th Order):**
* **DO NOT** attempt to decode all 64 channels in the browser.
* **Slice** the first 16 channels (Channels 0–15). This effectively creates a "3rd Order Proxy" of the high-res file.
* Feed this Proxy into the visualizer/binaural monitor.
* *UX Note:* Display a toast warning: *"Monitoring at 3rd Order (Proxy). Export will remain High-Res [N]th Order."*






* **B. File Export (Backend - `resources/scripts/rotate_ambisonics.py`)**
* **Library:** Use `numpy` and `scipy`.
* **Math:** Implement **Recursively Generated Wigner-D Matrices**.
* *Do NOT* hardcode matrices for orders 1–3.
* *DO* use a recursive algorithm (like standard SH rotation formulas) that accepts `order = N` and generates the correct  matrix.


* **Process:** Load File  Detect Order  Generate Matrix  Dot Product  Save.
