**1. Fix Audio Preview (The Silent Bug)**

* **Symptoms:** The audio file loads, but does not play.
* **Diagnosis:**
1. **Pathing:** In Electron, you cannot just pass `/Users/name/file.wav` to an `<audio>` element or Web Audio API. You must prepend `file://`.
2. **Autoplay Policy:** Browsers (including Chromium/Electron) start AudioContext in a `suspended` state. It must be explicitly `resumed` after a user interaction.


* **Fix Requirements:**
* Ensure the file path passed to the loader is formatted: `const url = 'file://' + filePath`.
* In the `handlePlay()` function, add this check:
```javascript
if (audioContext.state === 'suspended') {
    await audioContext.resume();
}

```


* Add `console.error` logs in the loading `catch` block so we can see if decoding is failing.



**2. Fix Orientation Buttons (The "Macro" Logic)**

* **Current Defect:** Buttons are invisible math modifiers. They do not update the sliders.
* **Requirement:** The buttons must act as **Two-Way Bound Toggles** for the sliders.
* **New Logic:**

* **Moving a Slider (Manual Override):**
* If the user manually drags the Roll slider to `180`, the "Upside Down" button automatically highlights.
* If the user drags it to `179`, the button turns off.
