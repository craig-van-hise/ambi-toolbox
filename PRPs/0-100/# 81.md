# Product Requirements Prompt (PRP): Phase 1 - Backend Demolition & Codebase Sterilization

## 1. Context & Objective
status: ✅ Completed

We are permanently abandoning the FFmpeg `pan` matrix and `sofalizer` filtergraph approach for binaural decoding due to fundamental mathematical limitations in FFmpeg's layout handler. We will be migrating to the Open Binaural Renderer (OBR) in the next phase.

**Your Objective:** Rip out all custom DSP matrix math, spherical harmonics, and binaural filtergraphs from the codebase. You must return the Node.js streaming backend to a "dumb" state where it simply reads the audio file and pipes a standard stereo downmix to the frontend so the app continues to compile and play.

## 2. Action 1: Delete the DSP Math
status: ✅ Completed

* **Task:** Locate and completely delete the file containing the matrix generation logic (e.g., `matrix_utils.ts`, `matrix_utils.js`, or wherever the `HexadecagonalGrid` and Spherical Harmonic trigonometry were hardcoded).
* **Cleanup:** Remove any `import` statements referencing this file across the entire backend.

## 3. Action 2: Gut the Streaming Endpoint
status: ✅ Completed

* **Task:** Open the backend streaming route (e.g., `electron/main.ts` or your stream handler file).
* **Remove:** Delete all logic related to:
* Checking for the 26-point or 16-point layouts.
* The two-pass volume normalization and `scaleFactor` calculations.
* Building the `filter_complex` string (remove `pan`, `sofalizer`, and `volume` filters).


* **Simplify the FFmpeg Spawn:** Strip the FFmpeg `child_process.spawn` arguments down to the absolute bare minimum required to stream a stereo WebM to the frontend.
* **Required Arguments:** `-i [input_file] -ac 2 -f webm -c:a libopus -b:a 192k pipe:1`
* Remove the `-ch_layout 16c` flag, as we are letting FFmpeg natively downmix to stereo (`-ac 2`) for now.



## 4. Action 3: Verify the "Dumb" Stream
status: ✅ Completed

1. Run `npm run dev` or your standard test script.
2. Ensure the app compiles without missing module errors.
3. Ensure that passing an Ambisonic file to the stream endpoint successfully outputs a basic, normalized 2-channel stereo WebM stream without crashing.

## 5. Acceptance Criteria
status: ✅ Completed

* The custom DSP/matrix utility files are completely removed from the file system.
* The FFmpeg spawn command contains zero audio filters (`-vf`, `-af`, or `-filter_complex`).
* The app compiles and plays stereo audio successfully.
