# Product Requirements Prompt: Implement Tool #8 (Ambix2APAC)

**Role:** Senior Software Architect
**Project Context:** AmbiToolbox (Electron/React/TypeScript Monolith)
**Objective:** Implement a new tool, **Ambix2APAC**, which converts Ambisonic `.wav` files into `.mp4` files encoded with the Apple Positional Audio Codec (APAC).

## 1. Architectural Strategy: The Native Sidecar
status: ✅ Completed

Since `AVAssetWriter` (Native macOS Swift) is required and cannot be called from Node.js, we will use a **Swift Sidecar** pattern.

1. **Swift Source (`native/apac-enc/`):** A lightweight Swift CLI tool importing `AVFoundation`.
2. **Electron Handler (`electron/handlers/Ambix2APAC.ts`):** Spawns the Swift binary.
3. **Frontend (`src/`):** React UI matching the existing strict color-coded design system.

## 2. Implementation Tasks
status: ✅ Completed

### Step A: The Swift Encoder (Native Backend)
status: ✅ Completed

Create `native/apac-enc/main.swift`.

* **Logic:**
* **Inputs:** `input_path`, `output_path`, `bitrate_per_channel`.
* **Detect:** Channel count (4, 9, 16, 25, 36).
* **Calculate Order:** `sqrt(channels) - 1`.
* **Calculate Total Bitrate:** `totalBitrate = bitrate_per_channel * channelCount`.
* **CRITICAL:** Force `AVChannelLayoutKey` to `kAudioChannelLayoutTag_HOA_ACN_SN3D`.
* **Encode:** Write to `.mp4` using `AVAssetWriter` with the calculated total bitrate.


* **Compilation:** Provide a build command to output `assets/bin/apac-enc`.

### Step B: Electron Main Process
status: ✅ Completed

Create `electron/handlers/Ambix2APAC.ts`.

* Locate `apac-enc` in `assets/bin/`.
* Spawn the process with arguments (`input`, `output`, `per_channel_bitrate`).
* Handle events (stdout/stderr) and report progress to UI.
