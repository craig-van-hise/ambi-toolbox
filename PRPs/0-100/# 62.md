# Product Requirements Prompt: AmbiTrim Editor Upgrade

**Context:**
The audio data is loading correctly, but the editor feels static. The waveform is too small, hard to manipulate, and lacks zoom controls.
**Goal:** Transform the visualizer into a full-screen, responsive editor with professional timeline controls.
**Key Features:**

1. **Responsive Height:** The waveform must fill 100% of the available vertical space.
2. **Zoom Engine:** Horizontal zoom (time) and Vertical zoom (amplitude).

## 1. Responsive Layout (Fill the Box)
status: ✅ Completed

**Objective:** Force Wavesurfer to resize dynamically when the window changes.

**File:** `src/components/tools/AmbiTrim.tsx`
**Logic:**

* Remove the hardcoded `height: 128` from the Wavesurfer config.
* Attach a `ResizeObserver` to the parent container (`div id="waveform-container"`).
* On resize, call `wavesurfer.setOptions({ height: container.clientHeight })`.

```tsx
// Inside useEffect...
const observer = new ResizeObserver(() => {
  if (wavesurferRef.current && containerRef.current) {
    wavesurferRef.current.setOptions({
      height: containerRef.current.clientHeight
    });
  }
});

observer.observe(containerRef.current);

// Cleanup
return () => observer.disconnect();

```

## 2. The Zoom Controls (Horizontal & Vertical)
status: ✅ Completed

**Objective:** Add a floating toolbar or header controls to manipulate the view.

**UI Component:** Add a toolbar above the waveform.

* **Horizontal Zoom:** Slider controlling `minPxPerSec`.
* Range: 10 (Fit to screen) to 200 (Detailed).


* **Vertical Zoom:** Slider controlling `barHeight` or re-normalizing.
* *Trick:* To "zoom vertically," simply increase the `barHeight` option (e.g., from 1.0 to 3.0). This stretches the peaks without changing volume.



```tsx
// State
const [zoomLevel, setZoomLevel] = useState(10); // Horizontal
const [ampLevel, setAmpLevel] = useState(1);    // Vertical

// Handlers
const onZoomChange = (e) => {
  const val = Number(e.target.value);
  setZoomLevel(val);
  wavesurferRef.current.zoom(val);
};

const onAmpChange = (e) => {
  const val = Number(e.target.value);
  setAmpLevel(val);
  wavesurferRef.current.setOptions({ barHeight: val });
};

```
