# Product Requirements Prompt (PRP): Node.js Binaural Streaming Backend

## 1. Context & Objective
status: ✅ Completed

The custom FFmpeg binary (`assets/bin/ffmpeg`) is successfully compiled with the `sofalizer` filter.
**Your Objective:** Build the backend Node.js streaming endpoint that takes an Ambisonic audio file (up to 7th order), decodes it to a virtual loudspeaker array (AllRAD approach) using FFmpeg, applies the user's custom HRTF via the `sofalizer` filter, and streams the live audio to the frontend transport.

## 3. Streaming Architecture (Native Node `http`)
status: ✅ Completed

Chromium's `<audio>` tag throws a `DEMUXER_ERROR` if fed a live-piped WAV stream because it lacks a file-size header. You must multiplex the live stream as WebM/Opus.

1. **Format:** WebM container with the Opus codec.
2. **Backend Output:** Configure the FFmpeg child process to output to `stdout` (`pipe:1`) with these exact arguments: `-f webm -c:a libopus -b:a 192k`.
3. **Bridge:** Use the native Node.js `http` module to create a local streaming server (e.g., `http://127.0.0.1:45455/stream`).
4. **Headers:** Set `res.setHeader('Content-Type', 'audio/webm');` before piping the FFmpeg `stdout` to the HTTP response.

## 4. Error Handling & Fallback Logic (Mandatory)
status: ✅ Completed

You must prevent the backend from crashing if the binaural setup is invalid. Before building the filtergraph and spawning FFmpeg:

1. **Validate Input:** Check if the requested `.sofa` file path is valid and not an empty string.
2. **Fallback Action:** If `binaural=true` but the `.sofa` path is empty/invalid, log a warning to the Node console, force `binaural=false`, and bypass the `pan`/`sofalizer` filtergraph entirely.
3. **Stereo Downmix:** When falling back (or if `binaural=false` natively), execute a standard stereo downmix stream (`-ac 2`) so playback continues uninterrupted.
4. **Logging:** Pipe the FFmpeg process's `stderr` directly to the Node console so internal decoding errors are visible.

## 5. Decoding Logic (AllRAD Virtual Loudspeakers)
status: ✅ Completed

When `binaural=true` and a valid SOFA file is present, we use an AllRAD approach to convert Ambisonics to binaural.

1. **Matrix Utility:** Write a JavaScript utility that generates an FFmpeg `pan` matrix string for a 3rd-order (16-channel) input.
2. **Filtergraph:** Map the Ambisonic input to a dense spherical grid using the `pan` filter, then pass those virtual speaker channels into the `sofalizer` filter. Example syntax: `[0:a] pan=... [virtual_speakers]; [virtual_speakers] sofalizer=sofa='/path/to/selected.sofa' [binaural_out]`
