

# Product Requirements Prompt: Fix Lines & Flag Geometry

**Severity:** BLOCKER
**Context:** The previous CSS left "double lines" or ghosting artifacts. The flags were not distinct.
**Goal:**

1. **Zero-Width Pole:** The pole must be a single 1px line derived from the pseudo-element, not the container border.
2. **Directional Flags:** Start Handle = Point Right. End Handle = Point Left.
3. **Clean Hit Area:** The clickable zone must be invisible.

## 1. The "Clean Flag" CSS

**File:** `src/components/tools/AmbiTrim.tsx`
**Action:** Replace the `<style>` block with this aggressive reset.

```tsx
<style>{`
  /* 1. PLAYHEAD (Red Line) */
  #waveform-container ::part(cursor) {
    width: 2px !important;
    background-color: #ff0000 !important;
  }

  /* 2. REGION (The Box) - No borders that look like handles */
  #waveform-container ::part(region) {
    border-top: 1px solid rgba(168, 85, 247, 0.5) !important;
    border-bottom: 1px solid rgba(168, 85, 247, 0.5) !important;
    border-left: 0 !important;  /* REMOVE SIDE BORDERS */
    border-right: 0 !important; /* REMOVE SIDE BORDERS */
    background-color: rgba(168, 85, 247, 0.15) !important;
    z-index: 10;
  }

  /* 3. THE HANDLE HIT ZONE (Transparent & Wide) */
  #waveform-container ::part(region-handle) {
    width: 20px !important;            /* Wide click target */
    background-color: transparent !important; /* INVISIBLE */
    cursor: ew-resize !important;
    border: 0 !important;              /* NO BORDERS ALLOWED */
  }

  /* 4. THE POLE (The Single White Line) */
  #waveform-container ::part(region-handle)::before {
    content: "";
    position: absolute;
    left: 50%;       /* Center in the 20px hit zone */
    top: 0;
    bottom: 0;
    width: 1px;      /* RAZOR THIN LINE */
    background-color: white;
    transform: translateX(-50%);
    pointer-events: none;
    z-index: 15;
  }

  /* 5. THE FLAG (Triangle Geometry) */
  #waveform-container ::part(region-handle)::after {
    content: "";
    position: absolute;
    top: 0;
    width: 12px;
    height: 12px;
    background-color: #a855f7; /* Purple Flag */
    pointer-events: none;
    z-index: 20;
  }

  /* 6. START HANDLE -> Point RIGHT */
  /* Target the handle on the left side of the region */
  #waveform-container [data-region-handle="left"]::part(region-handle)::after,
  #waveform-container [data-region-handle="start"]::part(region-handle)::after {
    left: 50%; /* Start at pole */
    /* Clip Path: Top-Left, Top-Right (long), Bottom-Left */
    clip-path: polygon(0 0, 100% 0, 0 100%);
  }

  /* 7. END HANDLE -> Point LEFT */
  /* Target the handle on the right side of the region */
  #waveform-container [data-region-handle="right"]::part(region-handle)::after,
  #waveform-container [data-region-handle="end"]::part(region-handle)::after {
    right: 50%; /* Start at pole, extend left */
    /* Clip Path: Top-Left (long), Top-Right, Bottom-Right */
    clip-path: polygon(0 0, 100% 0, 100% 100%);
  }
`}</style>

```

2. **Line Check:** Look at the Start Handle. Do you see **ONE** crisp white pixel line?
3. **Flag Check:** Does the flag point **INWARD** (Right)?
4. **Ghost Check:** Are there any extra borders floating next to the handle? (There should be none).
