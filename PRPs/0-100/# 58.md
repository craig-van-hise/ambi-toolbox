
# Product Requirements Prompt: Implement "Mid-Side" Stereo Proxy

**Context:**
The current proxy generation is producing silent or flat files.
**Goal:** Generate a true **Stereo** proxy by mathematically decoding the Ambisonic B-Format (W and Y channels) into Left/Right stereo.
**Method:** Use FFmpeg's `pan` filter to apply the Mid-Side decoding matrix.

## 1. Backend: The "Mid-Side" Matrix (`trim.ts`)

**File:** `electron/handlers/trim.ts`
**Objective:** Replace the `generateProxy` FFmpeg command with a manual pan filter.

**The FFmpeg Logic:**

* **Input:** Ambisonic Master (Channel 0=W, Channel 1=Y).
* **Filter:** `pan=stereo|c0=c0+c1|c1=c0-c1`
* *Left* = Omni + Side
* *Right* = Omni - Side


* **Normalization:** We must normalize (`-ac 2` implies some gain changes, but explicit normalization is safer) or just rely on the math. The addition will boost gain by +3dB, so we reduce gain slightly to prevent clipping.

**Update `generateProxy` Code:**

```typescript
const args = [
  '-y',
  '-i', filePath,
  
  // THE FIX: Manual Matrix Decode (W+Y / W-Y)
  // c0 is Left, c1 is Right. 
  // We use input c0 (W) and input c1 (Y).
  // Multiplied by 0.5 to prevent clipping.
  '-filter_complex', '[0:a]pan=stereo|c0=0.5*c0+0.5*c1|c1=0.5*c0-0.5*c1[out]',
  '-map', '[out]',
  
  // STANDARD FORMATTING
  '-c:a', 'libmp3lame',    // MP3 is widely compatible
  '-b:a', '192k',          // Decent quality
  '-ar', '44100',          // Standard sample rate
  
  outputPath
];

```
