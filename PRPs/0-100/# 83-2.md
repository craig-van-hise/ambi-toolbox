However, before you write the `CMakeLists.txt` and `obr_stream.cc`, you must adhere to the following critical build constraints:

## 1. The Abseil Dependency (CMake)

The OBR library depends on `abseil-cpp`. To ensure this compiles cleanly across all environments without requiring the user to install system-level packages, your `CMakeLists.txt` MUST use `FetchContent` to pull Abseil dynamically.

**Required CMake Logic:**

```cmake
include(FetchContent)
FetchContent_Declare(
  absl
  GIT_REPOSITORY https://github.com/abseil/abseil-cpp.git
  GIT_TAG 20240116.2 # Use a recent, stable LTS tag
)
set(ABSL_PROPAGATE_CXX_STD ON)
FetchContent_MakeAvailable(absl)

```

Ensure your `obr_stream` executable links against both the `obr` library and the necessary `absl::` targets.

## 2. Windows Binary Stream Safety (`obr_stream.cc`)

As previously established, you must explicitly force `stdin` and `stdout` into binary mode to prevent Windows from corrupting the raw PCM float data with CRLF line-feed injections.

**Required C++ Logic:**

```cpp
#ifdef _WIN32
#include <fcntl.h>
#include <io.h>
// Call this at the very beginning of main()
_setmode(_fileno(stdin), _O_BINARY);
_setmode(_fileno(stdout), _O_BINARY);
#endif

```
