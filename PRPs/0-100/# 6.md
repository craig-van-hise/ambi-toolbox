**Task:**
Implement the Full Stack (Frontend UI + Backend Logic) for the **AmbiRotate** tool.

**1. Context & Complexity**

* **Goal:** Correct microphone orientation issues (Yaw/Pitch/Roll) post-shoot.
* **Difficulty:** While Yaw (Z-rotation) is simple, Pitch/Roll on 3rd Order Ambisonics requires complex Spherical Harmonic rotation matrices (Wigner-D functions).
* **Architecture Decision:**
* **Preview:** Use **Web Audio API** (Client-side JS) for real-time approximation so the user can hear changes instantly.
* **Export:** Do **NOT** try to force FFmpeg to do this. Create a small **Python Helper Script** (`rotate_ambisonics.py`) that uses `numpy` to process the file mathematically, and call it from Electron.



**2. Frontend Requirements (`src/tools/AmbiRotate/index.tsx`)**

* **The "Cockpit" (Controls):**
* **3 Sliders:** Yaw, Pitch, Roll.
* Range: -180° to +180° (Yaw/Roll), -90° to +90° (Pitch).
* *UX:* "Slider Right = Sound moves Right" (Scene Rotation).


* **Quick Fix Buttons (Presets):**
* [Upside Down] (Sets Roll to 180°).
* [Rotate 180] (Sets Yaw to 180°).
* [Reset] (Zeros all).




* **The Transport (Preview):**
* **Controls:** Play, Pause, **Loop** (Critical for tuning), Stop.
* **Bypass Toggle:** "Hear Original" vs. "Hear Rotated."


* **Visualizer:** A simple Compass or "Head" icon that rotates based on the Yaw slider value to give visual orientation.

**3. Audio Engine Strategy**

* **A. Real-Time Preview (Frontend):**
* Use a lightweight JS library (like `ambisonics` or `omnitone`) in the browser.
* Load the dropped file into an `AudioContext`.
* Apply the rotation to the decoder node based on the slider values.
* *Note:* This is for monitoring only. It does not need to be bit-perfect, just directionally correct.


* **B. File Export (Backend):**
* Create `resources/scripts/rotate.py`.
* **Logic:** Load Audio  Generate Rotation Matrix (based on Euler angles)  Matrix Multiply  Save Audio.
* **Electron Handler (`ambirotate.ts`):** Spawn this Python script, passing the input path, output path, and Y/P/R angles as arguments.



**4. Deliverables**

1. `src/tools/AmbiRotate/index.tsx` (UI with Sliders & Transport).
2. `resources/scripts/rotate.py` (The math engine).
3. `electron/handlers/ambirotate.ts` (The bridge).
4. **Verification:** Ensure "Looping" works in the preview so users can fine-tune the center channel.
