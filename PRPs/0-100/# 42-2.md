
### PRP 42-2: The "Smart Drop Zone" Component

**Objective:** Create a unified Drag-and-Drop component that bridges the gap between raw DOM events (Legacy) and file lists (New).

> **Instruction for Agent:**
> Create a new React component at `src/components/SmartDropZone.tsx`.
> **Functional Requirements:**
> 1. **Dual Mode Support:** The component must accept two optional props:
> * `onDrop`: A legacy handler receiving a raw `React.DragEvent`.
> * `onFilesLoaded`: A modern handler receiving an array of `File` objects or file paths.
> 
> 
> 2. **Input Logic:**
> * When a user drops files, if `onFilesLoaded` is present, process the files (using the `window.electronAPI.expandPaths` if available) and return the data.
> * Always fire `onDrop` if it is provided (compatibility mode).
> 
> 
> 3. **Click-to-Upload:**
> * The drop zone area must be clickable.
> * On click, trigger `window.electronAPI.selectFiles` if it exists.
> 
> 
> 
> 
> **Visual Requirements:**
> * **Strict Style Preservation:** Use the exact same Tailwind CSS classes currently used in `Ambix2Opus` or `AmbiRotate` for the drop zone container (dashed border, rounded corners, centered text, gray hover states).
> * Do not invent new styles; standardized "Look and Feel" is the goal.
> 
>
