

# Product Requirements Prompt: Fix Local Media Playback (Protocol Handler)

**Context:**
The "AmbiTrim" tool successfully generates a proxy file (judging by the processing delay), but `wavesurfer.js` cannot load it. The UI shows a black box and playback fails.
**Root Cause:** Electron's renderer is blocking direct access to local file paths (`file://`).
**Solution:** Implement a `media://` protocol in the Main Process to act as a secure file server for the generated proxies.

## Step 1: Register Protocol in Main Process

**File:** `electron/main.ts` (or `index.ts` depending on your setup)
**Task:** Add the `handle` logic for the 'media' scheme **before** the app is ready.

```typescript
import { app, protocol, net } from 'electron';
import path from 'path';
import { pathToFileURL } from 'url';

// 1. REGISTER SCHEME (Must be done before app.on('ready'))
protocol.registerSchemesAsPrivileged([
  { scheme: 'media', privileges: { secure: true, supportFetchAPI: true, bypassCSP: true } }
]);

app.whenReady().then(() => {
  // 2. HANDLE REQUESTS
  protocol.handle('media', (request) => {
    // Convert "media://path/to/file.mp3" -> "file:///path/to/file.mp3"
    const filePath = request.url.replace('media://', '');
    
    // Decoding is crucial for paths with spaces (e.g., "My Audio File.wav")
    const decodedPath = decodeURIComponent(filePath);
    
    // Return the file response safely
    return net.fetch(pathToFileURL(decodedPath).toString());
  });

  // ... (rest of your createWindow logic)
});

```

## Step 2: Update Frontend Integration

**File:** `src/components/tools/AmbiTrim.tsx`
**Task:** When the proxy path returns from the backend, prepend the custom protocol before passing it to Wavesurfer.

```typescript
// Inside your component logic where you handle the file drop/generation:

const handleFileProcess = async (originalFile: string) => {
  setIsProcessing(true);
  try {
    // 1. Generate the raw path (e.g., "/var/folders/xyz/proxy.mp3")
    const rawProxyPath = await window.electron.trim.generateProxy(originalFile);
    
    // 2. CONVERT TO SAFE URL
    // Windows vs Mac/Linux handling might differ slightly, but usually:
    // If rawPath starts with "C:\" or "/", just prepend "media://"
    // Ideally, ensure rawProxyPath is absolute.
    
    const safeMediaUrl = `media://${rawProxyPath}`; 
    
    console.log("Loading into Wavesurfer:", safeMediaUrl); // Debug log
    
    // 3. Load into Wavesurfer
    wavesurferRef.current.load(safeMediaUrl);
    
    // 4. Update State
    setProxyPath(safeMediaUrl);
    
  } catch (err) {
    console.error("Proxy generation failed:", err);
  } finally {
    setIsProcessing(false);
  }
};

```

## Step 3: Verify CSP (Content Security Policy)

**File:** `electron/index.html` (or wherever your CSP meta tag is defined)
**Task:** Ensure `media:` is allowed in the `media-src` and `connect-src` directives.

```html
<meta http-equiv="Content-Security-Policy" content="
  default-src 'self'; 
  script-src 'self' 'unsafe-inline'; 
  media-src 'self' media: blob: data:; 
  connect-src 'self' media:;
">

```
