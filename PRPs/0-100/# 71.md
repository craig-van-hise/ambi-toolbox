# Product Requirements Prompt (PRP): Automated FFmpeg Recompilation (LGPL)

## 1. Context & Objective
status: ✅ Completed

We need to recompile our custom FFmpeg v6.1 binary for the "AmbiToolbox" project. The current binary at `assets/bin/ffmpeg` lacks the `sofalizer` filter, which is required for our upcoming binaural streaming feature.

**Your Objective:** Write and execute a temporary shell script (or run the terminal commands) to download the FFmpeg source, install the required `libmysofa` dependency, compile the binary using a strict LGPL configuration, place the new binary in our assets folder, and clean up the build directory.

## 2. Strict Constraints (The "God Rules")
status: ✅ Completed

* **NO NPM:** Do NOT run `npm install` or modify `package.json`. This task is strictly about C-compilation and the file system.
* **SANDBOX THE BUILD:** Do not dump the FFmpeg source code into the root of this repository. You must do the cloning and building in a temporary directory (e.g., `./ffmpeg_build_temp`) and add that directory to `.gitignore` immediately so it doesn't pollute source control.
* **COMMERCIAL LICENSING:** You must use the exact `./configure` command provided below. Do not add `--enable-gpl` or `--enable-nonfree`.

## 3. Execution Steps
status: ✅ Completed

**Step 1: Install the C Library Dependency**
status: ✅ Completed
Ensure `libmysofa` is installed on the host machine so `pkg-config` can find it.

* Execute: `brew install libmysofa` (Assuming macOS host based on project paths).

**Step 2: Prepare the Workspace**
status: ✅ Completed

1. Create a directory named `ffmpeg_build_temp` in the project root.
2. Ensure `ffmpeg_build_temp/` is added to `.gitignore`.
3. Clone the release 6.1 branch of FFmpeg into this temp folder:
`git clone --branch release/6.1 --depth 1 https://git.ffmpeg.org/ffmpeg.git ffmpeg_build_temp/src`

**Step 3: Configure and Build**
status: ✅ Completed
Navigate into `ffmpeg_build_temp/src` and execute the following configuration exactly as written:

```bash
./configure \
  --prefix="$PWD/../build_output" \
  --enable-lgpl \
  --disable-gpl \
  --disable-nonfree \
  --disable-libx264 \
  --disable-libx265 \
  --enable-libopus \
  --enable-libmp3lame \
  --enable-audiotoolbox \
  --enable-libmysofa \
  --disable-ffplay \
  --disable-doc \
  --pkg-config-flags="--static"

```

Once configured, compile the source:
`make -j8 && make install`

**Step 4: Deploy and Verify**
status: ✅ Completed

1. Copy the resulting binary from `ffmpeg_build_temp/build_output/bin/ffmpeg` to the project's asset directory: `assets/bin/ffmpeg` (overwrite the existing file).
2. Verify the filter was compiled successfully by running:
`./assets/bin/ffmpeg -filters | grep sofalizer`
*(It must output details about the sofalizer filter).*

**Step 5: Clean Up**
status: ✅ Completed
Once the binary is verified and in `assets/bin/ffmpeg`, forcefully delete the entire `ffmpeg_build_temp` directory to free up disk space and keep the project clean.

## 4. Acceptance Criteria
status: ✅ Completed

* The new `ffmpeg` binary sits at `assets/bin/ffmpeg`.
* Running the verification command shows `sofalizer` is present.
* The workspace is clean, with no leftover FFmpeg source files or build artifacts.
