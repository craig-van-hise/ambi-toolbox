Implement the **"Public Folder Injection"** strategy. This is the only fail-safe way to load legacy UMD libraries in strict ESM environments.

**Step 1: The "Physical" Move (Vendor the File)**

1. Navigate to `node_modules/ambisonics/` (or `node_modules/jsambisonics/`).
2. Find the build file (usually `ambisonics.umd.js` or `ambisonics.min.js`).
3. **COPY** this file.
4. **PASTE** it into your project's **public static folder** (e.g., `public/ambisonics.js`).
* *Crucial:* It must be in the folder that gets served to the root `/` URL, not inside `src/`.



**Step 2: The "HTML" Injection**

1. Open `index.html` (the root HTML file).
2. Add this line inside the `<head>` tag, *before* the React script:
```html
<script src="/ambisonics.js"></script>

```


3. *Why:* This forces the browser to load and execute the script *before* your app starts. It will attach the library to `window.ambisonics` (or `window.JSAmbisonics`).
