## 2. Interaction Config: Stop the Flicker

**Diagnosis:** The "flickering" happens when you drag the waveform and the browser tries to scroll the container while Wavesurfer tries to move the Playhead.

**Fix:** explicitly configure interaction modes in `WaveSurfer.create`.

```typescript
const ws = WaveSurfer.create({
  // ... other options
  height: 'auto',       // Let ResizeObserver handle the height pixels
  minPxPerSec: 0,       // Start at 0 to allow "Fit to Screen"
  fillParent: true,     // Crucial for filling width
  interact: true,       // Allow clicking
  dragToSeek: true,     // Dragging moves the playhead
  autoScroll: true,     // Scroll follows playhead
  autoCenter: true,
  cursorWidth: 2,
  cursorColor: '#ff0000', // RED Playhead
});

```

## 3. The "Fit to Screen" Logic (Zoom Fix)

**Logic:** When the Zoom slider is at 0, we must calculate the exact `minPxPerSec` required to fit the entire duration into the current container width.

```typescript
const handleZoom = (e: React.ChangeEvent<HTMLInputElement>) => {
  if (!wavesurferRef.current) return;
  
  const value = Number(e.target.value); // 0 to 100
  const duration = wavesurferRef.current.getDuration();
  const width = containerRef.current?.clientWidth || 800;
  
  if (value === 0) {
     // FIT TO SCREEN MODE
     // Logic: containerWidth / duration = pixels per second
     const fitRatio = width / duration;
     wavesurferRef.current.zoom(fitRatio);
  } else {
     // ZOOMED MODE
     // Scale up exponentially for better feel
     wavesurferRef.current.zoom(value * 5); 
  }
};

```

  width: 16px !important; /* Wider hit area */

  cursor: col-resize;

  position: absolute;
