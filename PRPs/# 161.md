# Product Requirements Prompt (PRP) — ✅ Completed

## 1. Project Context & Objectives
**Context:** The `Ambix2Bin` tool's HRTF selection logic was recently migrated from storing raw filenames to strict IDs (e.g., `'neumann'`, `'kemar'`).
**Issue:** The user is trapped by legacy state. `SettingsContext` is blindly loading the old filename string (`"Neumann_KU100_48k.sofa"`) from `localStorage`. The execution component (`ToolViews.tsx`) sees this unrecognized string, falls back to treating it as a custom path, and sends `{ type: 'custom', customPath: "Neumann_KU100_48k.sofa" }` to the backend, causing the file-existence check to fail.
**Objective:** Intercept and sanitize the raw `localStorage` payload in `SettingsContext.tsx` before it enters the React state, ensuring all legacy strings are migrated to their corresponding new IDs. Secure the IPC payload construction in `ToolViews.tsx`.

## 2. Technical Decisions & Dependencies
1.  **State Sanitization (Migration):** `SettingsContext.tsx` must actively inspect `toolSettings.ambix2bin.hrtfProfile` upon parsing `localStorage`. If it contains `.sofa`, it must be hard-reset to `HrtfProfile.Neumann`.
2.  **Strict Payload Construction:** The export function in `ToolViews.tsx` must explicitly map the `SettingsContext` values into the `HrtfSelection` interface.

## 3. Implementation Phases

### Phase 1: LocalStorage Migration (SettingsContext) — ✅ Completed
* **Objective:** Prevent legacy string formats from ever entering the React runtime state.
* **Instructions:**
    1. Open `src/contexts/SettingsContext.tsx`.
    2. Inside the state initialization function (`useState<AppSettings>(() => { ... })`), immediately after `const parsed = JSON.parse(saved);`, add a migration block:

       ```typescript
       // Sanitize legacy Ambix2Bin settings

           const currentProfile = parsed.toolSettings.ambix2bin.hrtfProfile;
           if (typeof currentProfile === 'string' && currentProfile.includes('.sofa')) {
               console.warn('[SettingsContext] Migrating legacy HRTF profile string to ID format.');
               parsed.toolSettings.ambix2bin.hrtfProfile = 'neumann'; // Default to ID

       ```
