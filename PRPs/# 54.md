
# Product Requirements Prompt: Fix AmbiTrim UI Layout

**Context:**
The previous attempt resulted in a UI bug where two "Drop Zones" were rendered simultaneously (stacked vertically). This is incorrect.
**Goal:** Fix `AmbiTrim.tsx` to strictly match the layout of "Ambix2Opus".
**Golden Rule:** The "Drop Zone" and the "Waveform Viewer" occupy the **exact same pixel space**. They are mutually exclusive. You must never see both at the same time.

## 1. The Layout Architecture (Strict Enforcement)

You are to implement a single Flexbox column that fills 100% of the right-hand pane.

### The Component Tree

```tsx
<div className="flex flex-col h-full bg-slate-900 text-white">
  
  {/* 1. HEADER (Fixed) */}
  <div className="p-8">

    <p className="text-gray-400 mt-2">Lossless trimming for Ambisonic master files.</p>
  </div>

  {/* 2. DYNAMIC WORKSPACE (Flex-Grow / Flex-1) */}
  {/* This is the ONLY place where content changes based on state. */}
  <div className="flex-1 relative min-h-0 overflow-hidden"> 
    {/* CONDITIONAL LOGIC IS MANDATORY HERE */}
    { !fileLoaded ? (
       <DropZoneComponent /> 
    ) : (
       <WaveformEditorComponent /> 
    )}
  </div>

  {/* 3. CONTROL DECK (Fixed Height Footer) */}
  <div className="border-t border-gray-700 bg-slate-800 p-6">
     {/* Inputs and Export Button go here */}
  </div>

</div>

```

## 2. Implementation Rules

### Rule A: The "State Switch"

* **Do not** place a Drop Zone in the "Control Deck" (Footer).
* **Do not** place a Drop Zone above another Drop Zone.
* Initialize state: `const [file, setFile] = useState<string | null>(null);`
* **If `file` is null:** Render *only* the standard Drop Zone (dashed border, "Drag Audio Files...", standard icon). Use the exact same styling/component used in `Ambix2Opus`.
* **If `file` is set:** The Drop Zone must **unmount** completely. The `wavesurfer` container takes its place immediately.

### Rule B: The Footer (Control Deck)

* Look at "Ambix2Opus" (Screenshot 1). The footer has a solid background (darker/lighter than main).
* It contains **only**:
1. The Input Fields (Start Time / End Time).
2. The "Export" Button (Purple, Full Width).


* It must **never** contain a "Drag file here" instruction.
