# Product Requirements Prompt (PRP)

## 1. Project Context & Objectives
status: ✅ Completed
Playback for `.iamf` files is suffering from a "Ghosting" bug where the app plays audio from a previously loaded file even after a restart. Additionally, the `AmbiData` OBU parser is failing to detect streams in valid Ambisonic IAMF files, causing the `PlaybackContext` to report 0 channels and block playback.

The objective is to implement a **Deterministic Ingestion Cache** and a **Recursive OBU Scanner** to ensure that every IAMF file is uniquely identified and fully parsed regardless of its internal bitstream profile.

## 2. Technical Decisions & Dependencies
status: ✅ Completed
* **Robust Hashing:** The `IngestionRouter` must switch from filename-based hashing to **Stat-Based Hashing**. The hash must be generated using `filePath + fileSize + modificationTime`. This ensures that even if two files have the same name, the router will treat them as unique entities.
* **Stream Generation:** To solve the user's "lack of test files," the agent must verify the `Ambix2IAMF.ts` handler. The user should be instructed to use the internal **Ambix2IAMF tool** to convert their 16-ch WAVs into IAMF files for local baseline testing.

## 3. Implementation Phases
status: ✅ Completed

### Phase 1: Fix the Ghosting (Stat-Based Hashing)
status: ✅ Completed
* **Objective:** Ensure the `IngestionRouter` never misidentifies a file.
* **Instructions:**
    1. Open `electron/handlers/IngestionRouter.ts`.
    2. Modify the `generateHash` function.
    3. Use `fs.statSync(filePath)` to retrieve the `size` and `mtimeMs`.
    4. Create the hash using a combination of the absolute path and these stats: `crypto.createHash('md5').update(`${path}-${size}-${mtime}`).digest('hex')`.
    5. Update `prepareStreamTarget` to use this new deterministic hash for the `.ambi_tmp.wav` filename.
* **TDD Checkpoint:**

### Phase 2: Recursive OBU Parsing (`AmbiData.ts`)
status: ✅ Completed
* **Objective:** Fix the "0ch" metadata bug by hardening the IAMF stream detector.
* **Instructions:**

    3. If the parser finds an `Audio Element` but cannot find an `IAMF_PROFILE` tag, it MUST default to a "Generic Scene-Based" assumption if 16 channels are detected, rather than returning 0.
    4. Update the `analyze-ambi-file` IPC handler to return the highest channel count found across all valid OBUs.

### Phase 3: Forced Pipeline Reset
status: ✅ Completed
* **Objective:** Ensure no audio data lingers in the pipeline between file swaps.
* **Instructions:**

    2. In the `/stream` and `/obr-stream` handlers, implement a `res.setHeader('X-Content-Signature', currentFileHash)` header.
    3. In `PlaybackContext.tsx`, ensure that every time `setCurrentFile` is called, the internal `audio.src` is explicitly cleared to `about:blank` before the new URL is assigned to force a full browser-level buffer purge.
