# Product Requirements Prompt (PRP) — 🔵 Active

## 1. Project Context & Objectives
The application requires an immediate resolution to playback and rotation latency. The current architecture imposes an artificial 1.5s buffering delay. The objective is to implement a high-performance, local-only PCM streaming pipeline that provides near-instantaneous audio updates for playback, seeking, and real-time spatial rotation.

## 2. Technical Decisions & Dependencies
* **Buffer Reduction:** The `PrimeBuffer` threshold in `StreamServer.ts` must be slashed from 48KB to 4KB (near-zero delay). 
* **Uncompressed Streaming:** The streaming format will shift from Ogg/Opus to **WAV (PCM)**. This eliminates encoding overhead and allows the browser to begin playback the moment the first sample arrives. 
* **Input Bypassing:** FFmpeg's decoder will be instructed to skip analysis using `-probesize 32` and `-analyzeduration 0`. 
* **UI Responsiveness:** The rotation debounce in the frontend will be tightened to **150ms** for a "live" feel.
