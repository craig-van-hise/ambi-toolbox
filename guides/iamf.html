OBU_IA_Sequence_Header OBU Type 31
The global configuration for the entire IAMF stream, defining profiles and versioning[cite: 318]. 🔗
primary_profile Value
Dictates the complexity tier of the stream (e.g., Simple, Base, or Base-Enhanced)[cite: 340, 341, 342].
OBU_IA_Codec_Config OBU Type 0
Defines the specific codec initialization data. Essential for setting up the audio decoder[cite: 317, 351]. 🔗
codec_id 4 Bytes
A FourCC code identifying the format, such as Opus, mp4a, fLaC, or ipcm[cite: 353, 355, 356, 357, 358].
audio_roll_distance Value
Critical for random access; specifies how many samples prior to the target timestamp must be decoded to prime the decoder's internal state[cite: 362, 363].
OBU_IA_Audio_Element OBU Type 1
Describes the structure of an audio object, channel bed, or Ambisonics scene, defining how substreams are combined[cite: 317, 367].
audio_element_type Value
Fundamentally changes how the decoder interprets the subsequent data (0=Channel Based, 1=Scene Based, 2=Object Based)[cite: 369, 370, 371].
ScalableChannelLayoutConfig Struct
Allows a decoder to download/decode only the channels it needs. Triggered by Type 0[cite: 370, 373, 374].
Includes num_layers (hierarchy depth) and loudspeaker_layout (channel config)[cite: 376, 377].
expanded_loudspeaker_layout 8-Bit
Parsed when layout is set to 15. Supports ultra-immersive setups like 9.1.6ch or 10.2.9.3ch[cite: 384, 385, 386]. 🔗
OBU_IA_Mix_Presentation OBU Type 2
Contains the rendering and mixing rules (loudness, gain, layout targeting) for the final output[cite: 317, 398].
Loudness Info (ITU-R BS.1770-4) Struct
Mandatory loudness compliance data. Carries integrated_loudness and maximum true_peak (dBTP)[cite: 411, 412, 418, 420]. 🔗
anchor_element Value
Allows content normalization based on a specific perceptual element (1=Dialogue Anchor, 2=Album Anchor)[cite: 423, 425, 428].
rendering_config Struct
Instructs the renderer on algorithmic application, including headphones_rendering_mode (Stereo vs Binaural)[cite: 430, 432, 435].
OBU_IA_Parameter_Block OBU Type 3
Carries time-varying dynamic metadata (demixing coefficients, spatial positions) for a specific duration[cite: 317, 442].
DemixingInfoParameterData Struct
Provides the mathematical key to unfold a downmix back into a high-channel-count mix[cite: 449].
Uses dmixp_mode to define parametric combinations (α, β, γ, δ)[cite: 451, 452].
SinglePositionParameterData Struct
Carries the 3D coordinates moving objects through space[cite: 446, 468].
